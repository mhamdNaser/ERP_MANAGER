# CND Manager FrontEnd

واجهة React + Vite لنظام CND Manager. التنقل الرئيسي مبني عبر `react-router-dom` داخل `src/Apihooks/route.jsx`، بينما يظل `AppShell.jsx` مسؤولاً عن عرض التبويبات المسموحة حسب صلاحيات المستخدم.

## التشغيل

```bash
npm install
npm run dev -- --host 127.0.0.1 --port 5173
```

إن كان الباك إند على `127.0.0.1:8000`، تأكد من إعدادات `.env`:

```env
VITE_API_BASE_URL=http://127.0.0.1:8000/api
VITE_DEV_API_TARGET=http://127.0.0.1:8000
VITE_REVERB_APP_KEY=cnd-local-key
VITE_REVERB_HOST=127.0.0.1
VITE_REVERB_PORT=8080
VITE_REVERB_SCHEME=http
```

## البناء

```bash
npm run build
```

## البنية

- `src/Layout/AppShell.jsx`: السايد بار، التوب بار، الإشعارات، وتبديل الصفحات.
- `src/Api/api.js`: كل endpoints المستخدمة في الواجهة.
- `src/Api/http.js`: التوكن، اللغة، JSON/FormData، والتنزيلات.
- `src/Apihooks/route.jsx`: تعريف مسارات التطبيق وتغليفها بالغلاف المناسب.
- `src/Apihooks/queryClient.js`: إعداد React Query المركزي.
- `src/Apihooks/use*.js`: هوكات الربط مع الباك إند مثل الداشبورد، الرسائل، الإشعارات، والفورمات.
- `src/realtime.js`: Laravel Echo + Reverb للرسائل الفورية.
- `src/Page/<Tab>/index.jsx`: الصفحة الرئيسية لكل تبويب، ومعها `components/` عند الحاجة لتجنب تضخم الملفات.
- `src/Page/FormalCorrespondences/index.jsx`: المراسلات الرسمية، الخط الزمني، وثائق Word/PDF، ومصادر/أهداف الوثائق.
- `src/Page/Reports/index.jsx`: التقارير والخطط، الفلاتر حسب الصلاحية، ومسار الاعتماد.
- `src/Page/Guide/index.jsx`: دليل الواجهات والفورمات.
- `helpJson/interfaceGuide.json`: نصوص الجولة الإرشادية.
- `src/utils/formData.js`: تحويل البيانات والملفات، ويدعم مصفوفات الملفات مثل `attachments[]`.

## React Query

- كل ربط متكرر مع الباك إند يجب أن يكون داخل `src/Apihooks` كـ hook واضح، وليس مباشرة داخل الصفحة.
- استخدم مفاتيح query مستقرة ومقسمة حسب النطاق، مثل الرسائل أو الإشعارات أو الداشبورد.
- عند تسجيل الدخول أو الخروج يتم تفريغ كاش React Query حتى لا تبقى بيانات حساب سابق ظاهرة لحساب جديد.

## الرسائل والمراسلات

`الرسائل` هي قناة داخلية فورية بين المستخدمين. تدعم:

- مرفقات للرسالة والرد.
- إشارات غير مقروءة في السايد بار وصف الرسالة.
- تحديث فوري عبر Reverb.
- حذف الرسالة من المصدر عند المرسل.

`المراسلات` هي سجل رسمي مختلف. تدعم:

- اتجاهات وارد/صادر وداخلي/خارجي.
- خطاً زمنياً لمحطات مرور المراسلة.
- عدة وثائق لكل محطة.
- مصدر وهدف لكل وثيقة.
- ملف مرفوع أو كتاب صادر عن مؤسستنا من قالب Word رسمي.
- QR داخلياً مع شعار أو علامة المؤسسة دون تغيير رقم الكود.
- توقيعاً رقمياً عائماً فوق النص داخل مساحة التوقيع حتى لا يزيح QR أو بقية المحتوى.

## التقارير والخطط

- ما ينطبق على التقارير ينطبق على خطط العمل في مسار المراجعة والاعتماد.
- الموظف يرى مسوداته والمرتجع إليه فقط، ورئيس القسم يرى ما ينتظر مراجعته في قسمه.
- رئيس القسم يمكنه الإرسال إلى مدير الفرع أو المدير العام، أو الإعادة للموظف مع سبب.
- مدير الفرع يراجع ما وصل إليه ويحوّله للمدير العام أو يعيده للموظف.
- بعد اعتماد المدير العام يصبح زر الإعادة معطلاً، وتبقى الرؤية للمدير العام ومدير قواعد البيانات.
- مدير قواعد البيانات يرى كل التقارير والخطط ويملك صلاحية تعديل كاملة عليها.

## تحديث الدليل

عند إضافة واجهة أو تغيير تدفق مهم:

1. حدّث `src/Page/Guide/index.jsx`.
2. حدّث `helpJson/interfaceGuide.json`.
3. حدّث `README.md` الرئيسي إن تغيرت البنية أو مسارات API.
