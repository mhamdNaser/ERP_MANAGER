# دليل CND Manager التقني

هذا المجلد هو المرجع الكامل للمشروع. كُتب لمبرمج جديد يريد أن يفهم النظام ويعدّل عليه
بأقل وقت ضائع. **كل شرح مرفق باسم الملف الذي ينفّذ الخطوة**، حتى تعرف أين تذهب مباشرة.

> الملفات القديمة (تقارير Word/PDF وسكربت QGIS) نُقلت كما هي إلى [attachments/](attachments/)
> ولم يُحذف منها شيء.

## مصطلحات ثابتة في كل الوثائق

| المصطلح | المعنى |
| --- | --- |
| **الفاعل / actor** | المستخدم الذي أرسل الطلب، يصل عبر `$request->user()` |
| **النطاق / scope** | حدود ما يراه المستخدم (مؤسسة، فرع، قسم، شخصي) |
| **الدور / role** | `employee`, `technician`, `department_head`, `branch_manager`, `general_manager`, `database_manager`, `office_manager` |
| **الصلاحية / permission** | سلسلة مثل `reports.view` تُفحص في المسار عبر `permission:` |
| **المحطة / stage** | خطوة في مسار اعتماد (تقرير أو طلب HR أو مراسلة) |
