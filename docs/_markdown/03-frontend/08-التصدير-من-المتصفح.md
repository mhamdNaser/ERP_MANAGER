# التصدير من المتصفح

## نظامان مختلفان للتصدير

| النظام | المكان | الناتج | الاستخدام |
| --- | --- | --- | --- |
| **تصدير من الخادم** | Laravel + قوالب Word | `.docx` + `.pdf` رسميان | الكتب الرسمية، طلبات HR |
| **تصدير من المتصفح** | JavaScript يبني HTML | `.doc` أو طباعة PDF | التقارير، إجابات الفورمات |

هذا الملف يشرح الثاني. للأول انظر `02-backend/06-توليد-Word-وPDF.md`.

> **متى تستخدم أيهما؟** الوثيقة الرسمية التي تحمل توقيعاً وQR ورقم ديوان ← الخادم.
> جدول أو تقرير للاستخدام المكتبي ← المتصفح (أسرع، بلا حمل على الخادم).

## `src/utils/exportHtml.js` — الأدوات

### الهروب والقيم

```js
export function escapeHtml(value) {
  return value
    .replaceAll("&", "&amp;").replaceAll("<", "&lt;").replaceAll(">", "&gt;")
    .replaceAll('"', "&quot;").replaceAll("'", "&#39;");
}

export function textValue(value, fallback = "—") {
  const trimmed = value?.trim();
  return escapeHtml(trimmed && trimmed.length ? trimmed : fallback);
}
```

> **`escapeHtml` إلزامي على كل قيمة تأتي من المستخدم.** بدونه يستطيع من يكتب
> `<script>` في عنوان تقرير أن يحقنه في الملف المصدَّر. `textValue` تجمع الهروب
> مع قيمة احتياطية `—` للحقول الفارغة.

### التواريخ

```js
export function formatDate(value, withTime = false) {
  if (!value) return "—";
  const date = new Date(value);
  if (Number.isNaN(date.getTime())) return escapeHtml(value);
  return date.toLocaleString("ar-EG", {
    year: "numeric", month: "2-digit", day: "2-digit",
    ...(withTime ? { hour: "2-digit", minute: "2-digit" } : {}),
  });
}
```

`ar-EG` مثبّت — التاريخ في الوثيقة المصدَّرة لا يتبع لغة الواجهة، لأن الوثائق
الرسمية عربية دائماً.

### تنزيل ملف Word

```js
export function downloadHtml(html, type, fileName) {
  const url = URL.createObjectURL(new Blob([`﻿${html}`], { type }));
  const anchor = document.createElement("a");
  anchor.href = url;
  anchor.download = fileName;
  anchor.click();
  window.setTimeout(() => URL.revokeObjectURL(url), 1000);
}
```

| التفصيل | السبب |
| --- | --- |
| `﻿` (BOM) | **بدونه يعرض Word النص العربي كرموز مشوّهة** |
| `URL.createObjectURL` | ينشئ رابطاً مؤقتاً للـBlob |
| `revokeObjectURL` بعد ثانية | تحرير الذاكرة بعد بدء التنزيل |

### الطباعة إلى PDF

```js
export function printHtml(html, size = "width=1000,height=800") {
  const printWindow = window.open("", "_blank", size);
  if (!printWindow) return;                    // حاجب النوافذ منعها
  printWindow.document.write(html);
  printWindow.document.close();
  printWindow.focus();
  window.setTimeout(() => printWindow.print(), 300);
}
```

لا تُنشأ PDF فعلياً — تُفتح نافذة ويُستدعى حوار الطباعة، والمستخدم يختار
"حفظ بصيغة PDF". تأخير 300 مللي ثانية يمهل المتصفح لتصيير المحتوى والخطوط.

> **إن أعاد `window.open` قيمة `null`** فحاجب النوافذ منع الفتح. الدالة تخرج بصمت —
> أضف تنبيهاً للمستخدم في الشيفرة الجديدة.

### أنماط الوثيقة — `documentStyles`

```css
:root{--forest:#06312D;--light:#f4f9f7;--line:#cfded9;--ink:#17201d;--muted:#5f6f6b;--gold:#c27c21}
body{font-family:'Noto Sans Arabic',Tahoma,Arial,sans-serif;line-height:1.7;
     -webkit-print-color-adjust:exact;print-color-adjust:exact}
.sheet{page-break-after:always}.sheet:last-child{page-break-after:auto}
th{background:var(--forest);color:#fff}
tbody tr:nth-child(even) td{background:var(--light)}
```

| القاعدة | السبب |
| --- | --- |
| `print-color-adjust:exact` | **بدونها يحذف المتصفح خلفيات الجداول عند الطباعة** |
| `page-break-after:always` | كل `.sheet` صفحة مستقلة |
| `Tahoma, Arial` احتياطي | إن لم يتوفر Noto Sans Arabic على جهاز المستخدم |
| ألوان صريحة | لا اعتماد على ثيم الواجهة — الوثيقة مستقلة |

## `src/Api/reportExportService.js`

```js
export function exportReports(reports, format) {
  if (!reports.length) return;
  const html = reportDocument(reports);
  if (format === 'word')
    return downloadHtml(html, 'application/msword;charset=utf-8',
      `CND-reports-${new Date().toISOString().slice(0, 10)}.doc`);
  printHtml(html);
}
```

بنية الوثيقة:

```
<!doctype html><html dir="rtl" lang="ar">
  <style>@page{size:Letter;margin:18mm 16mm} ...</style>
  <section class="sheet">            ← صفحة لكل تقرير
    <header>الشعار + رقم التقرير</header>
    <h1>العنوان</h1>
    <table class="meta">الفترة، الحالة، الفرع، القسم، المُرسِل</table>
    <h2>تفاصيل التقرير</h2>
    <table>الملخص، الإنجازات، التحديات، الخطوات التالية</table>
  </section>
```

`@page{size:Letter}` يضبط حجم الورق في حوار الطباعة.

## `src/Api/formSubmissionExportService.js`

يبني الأعمدة ديناميكياً من حقول الفورم:

```js
function columns(form) {
  return form.fields.map(field => ({ key: field.field_key, label: field.label }));
}

const headers = ['النسخة', 'الموظف', 'المسمى الوظيفي', 'الفرع', 'القسم',
                 'تاريخ التعبئة', ...columns(form).map(f => f.label)];
```

تنسيق القيم حسب النوع:

```js
function formValue(value) {
  if (Array.isArray(value)) return value.length ? value.join('، ') : '—';
  if (typeof value === 'boolean') return value ? 'نعم' : 'لا';
  return String(value ?? '—');
}
```

المصفوفات بفاصلة عربية `، ` والقيم المنطقية بـ"نعم/لا".

### الفرق بين وثيقتَي الفورم

| الصيغة | الخصائص |
| --- | --- |
| PDF | `size: Letter landscape` + `white-space:nowrap` + `text-overflow:ellipsis` — الجداول عريضة |
| Excel | جدول عارٍ بلا ترويسة ولا `@page` — Excel يتجاهلها |

Excel يفتح HTML يحوي `<table>` ويحوّله إلى ورقة عمل. حيلة قديمة لكنها تعمل
بلا مكتبات ولا خادم.

## إضافة نوع تصدير جديد

**1.** أنشئ `src/Api/<الاسم>ExportService.js`.

**2.** استورد الأدوات المشتركة:

```js
import { documentStyles, downloadHtml, escapeHtml, formatDate, printHtml, textValue }
  from '../utils/exportHtml';
```

**3.** ابنِ الوثيقة:

```js
function assetsDocument(assets) {
  return `<!doctype html><html dir="rtl" lang="ar"><head><meta charset="utf-8">
    <title>سجل العهد</title>
    <style>@page{size:Letter;margin:18mm 16mm}${documentStyles}</style></head>
    <body><section class="sheet">
      <header><div class="brand"><div class="mark">CND</div>
        <div><strong>إدارة الشبكات والاتصالات</strong><small>سجل العهد</small></div>
      </div></header>
      <table><thead><tr><th>الرمز</th><th>الاسم</th><th>الحائز</th></tr></thead>
      <tbody>${assets.map(a => `<tr>
        <td>${textValue(a.code)}</td>
        <td>${textValue(a.name)}</td>
        <td>${textValue(a.holder?.name)}</td></tr>`).join('')}
      </tbody></table>
    </section></body></html>`;
}

export function exportAssets(assets, format) {
  if (!assets.length) return;
  const html = assetsDocument(assets);
  if (format === 'word')
    return downloadHtml(html, 'application/msword;charset=utf-8',
      `CND-assets-${new Date().toISOString().slice(0, 10)}.doc`);
  printHtml(html);
}
```

**4.** صدّره من `src/lib.js` إن أردت اختصار الاستيراد:

```js
export { exportAssets } from './Api/assetsExportService';
```

## قواعد

| القاعدة | السبب |
| --- | --- |
| `escapeHtml()` على كل قيمة مستخدم | منع حقن HTML |
| `﻿` قبل محتوى Word | العربية تظهر مشوّهة بدونه |
| `print-color-adjust:exact` | الخلفيات تُحذف عند الطباعة بدونها |
| `dir="rtl" lang="ar"` على `<html>` | اتجاه الوثيقة |
| ألوان صريحة لا رموز الثيم | الوثيقة مستقلة عن الواجهة |
| `revokeObjectURL` بعد التنزيل | تحرير الذاكرة |
| افحص `reports.length` أولاً | لا تفتح نافذة فارغة |
| افحص نتيجة `window.open` | حاجب النوافذ قد يمنعها |
