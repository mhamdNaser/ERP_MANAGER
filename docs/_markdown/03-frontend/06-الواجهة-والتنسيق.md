# الواجهة والتنسيق

المرجع الأصلي: `FrontEnd/STYLEGUIDE.md`.

## اللغة البصرية

الواجهة **مسطّحة وهادئة وساكنة** — لغة لوحات التحكم الإدارية العالمية
(Linear / Vercel / Stripe)، لا موقع تسويقي.

### خمس قواعد غير قابلة للتفاوض

| # | القاعدة | التفصيل |
| --- | --- | --- |
| 1 | **لا حركة** | لا `animate-*` ولا `transition-*` ولا `@keyframes` ولا `transform` عند المرور ولا `backdrop-blur`. `src/index.css` يحوي مفتاح إيقاف عام، لكن لا تكتب حركة أصلاً |
| 2 | **لا ظلال زخرفية** | لا `shadow-lg` ولا `shadow-xl`. العمق من `border border-line`. `shadow-sm` فقط للطبقات العائمة |
| 3 | **نصف قطر واحد** | `rounded` (4px). لا `rounded-xl` ولا `rounded-2xl`. `rounded-full` للصور الرمزية ونقاط الحالة فقط |
| 4 | **لا تدرّجات** | لا gradients ولا توهّج ولا زخارف `::after` |
| 5 | **آمن لـRTL** | خصائص منطقية فقط — انظر `05-الترجمة-وRTL.md` |

## المكوّنات الأولية — `@layer components` في `src/index.css`

**استخدمها قبل أن تخترع بديلاً.**

| المجموعة | الأصناف |
| --- | --- |
| الأزرار | `btn btn-primary`, `btn btn-secondary`, `btn btn-ghost`, `btn btn-danger`, معدِّل `btn-sm`, و`btn-icon` للأزرار المربعة |
| النماذج | `field` (غلاف), `label`, `input`, `select`, `textarea`, `hint`, `error-text` |
| الأسطح | `card`, `card-head`, `card-body`, `panel` |
| الصفحة | `page`, `page-header`, `page-title`, `page-subtitle`, `eyebrow`, `section-title` |
| الجداول | `table-wrap` > `table` (التنسيق من `thead th` / `tbody td`) |
| الشارات | `badge badge-neutral\|brand\|ok\|warn\|danger\|info` |
| الطبقات | `overlay`, `modal`, `modal-head`, `modal-body`, `modal-foot`, `drawer` |
| متنوّع | `empty-state`, `divider`, `muted`, `stat-grid` |

مثال:

```jsx
<div className="card">
  <div className="card-head">
    <h2 className="section-title">{t("recentReports")}</h2>
  </div>
  <div className="card-body">
    <div className="table-wrap">
      <table className="table">...</table>
    </div>
  </div>
</div>
```

## مقياس الخطوط والمسافات

| العنصر | الصنف |
| --- | --- |
| نص المتن | `text-[13px]` |
| نص ثانوي | `text-xs` |
| تسميات الحقول | `text-xs font-semibold` |
| عناوين الأقسام | `text-sm font-semibold` |
| عنوان الصفحة | `text-xl font-semibold` |

> لا شيء أكبر من `text-2xl` خارج شاشة الدخول.

المسافات: `gap-2` / `gap-3` / `gap-4`، الحشو `p-3` / `p-4`،
هوامش الصفحة `p-4 lg:p-6`. لا تخرج عن هذا السلّم.

## تقسيم الصفحات الكبيرة

القاعدة: **لا ملف مصدر يتجاوز 400 سطر.** الصفحات الكبيرة مقسّمة:

```
src/Page/FormalCorrespondences/
├── index.jsx                       الصفحة والحالة العامة
└── components/
    ├── CreateFormalModal.jsx
    ├── FormalDetails.jsx
    ├── ProcessingTimeline.jsx
    ├── StageSidebar.jsx
    ├── StageDetailsModal.jsx
    ├── PartyPicker.jsx
    └── formalUtils.js              دوال مساعدة بلا JSX
```

| النمط | المحتوى |
| --- | --- |
| `index.jsx` | التخطيط والحالة والاستعلامات |
| `components/*.jsx` | مكوّنات فرعية |
| `*Utils.js` | دوال خالصة بلا JSX |
| `*Meta.jsx` | ثوابت العرض (ألوان الحالات، الأيقونات) |

مثال `taskMeta.jsx` — تعريف ألوان وتسميات الحالات في مكان واحد بدل تكرارها.

import { RefreshCw, LayoutDashboard, HardDrive } from "lucide-react";

## قائمة تحقق قبل دمج واجهة جديدة

- [ ] لا `transition-*` ولا `animate-*`
- [ ] لا `shadow-lg` ولا `shadow-xl`
- [ ] `rounded` فقط (عدا الصور الرمزية)
- [ ] خصائص منطقية: `ms-*` لا `ml-*`
- [ ] رموز الثيم: `bg-surface` لا `bg-white`
- [ ] الأولّيات مستخدمة: `btn btn-primary` لا أصناف مركّبة يدوياً
- [ ] مقياس الخطوط محترم
- [ ] جُرِّبت بالعربية والإنجليزية
- [ ] لا نص مكتوب مباشرة — كله عبر `t()`
- [ ] الملف أقل من 400 سطر
