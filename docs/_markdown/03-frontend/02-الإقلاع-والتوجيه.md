# الإقلاع والتوجيه

## سلسلة الإقلاع

```
index.html
   └─► src/main.jsx
         ├─ ضبط lang و dir على <html> من localStorage
         ├─ QueryClientProvider   (كاش React Query)
         └─ RouterProvider        (react-router)
               └─► src/App.jsx
                     ├─ LanguageProvider   (اللغة و t())
                     ├─ ConfirmProvider     (نوافذ التأكيد)
                     └─ Application
                           ├─ [1] ConnectionGate  ← فحص الخادم
                           ├─ [2] استرجاع الجلسة   ← GET /auth/me
                           ├─ [3] LoginPage        ← إن لا جلسة
                           └─ [4] AppShell         ← التطبيق
```

## `src/main.jsx`

```jsx
const initialLanguage = localStorage.getItem("LANGUAGE") || "ar";
document.documentElement.lang = initialLanguage;
document.documentElement.dir = initialLanguage === "ar" ? "rtl" : "ltr";

createRoot(document.getElementById("root")).render(
  <StrictMode>
    <QueryClientProvider client={queryClient}>
      <RouterProvider router={router} />
    </QueryClientProvider>
  </StrictMode>,
);
```

> **ضبط `dir` قبل التصيير مقصود.** لو انتظرنا React لظهرت وميضة بالاتجاه الخاطئ
> عند أول رسم. القراءة من `localStorage` مباشرةً تحسم الاتجاه قبل أي بكسل.

`StrictMode` يشغّل التأثيرات مرتين في التطوير — كل `useEffect` هنا مكتوب ليحتمل ذلك.

## `src/App.jsx` — البوابات الأربع

```jsx
function Application() {
  const [gate, setGate] = useState(false);
  const [user, setUser] = useState(null);
  const [restoring, setRestoring] = useState(Boolean(token.get()));

  useEffect(() => {
    if (!gate) return;
    const id = setTimeout(() => {
      if (token.get())
        api.me().then(setUser)
          .catch(() => { queryClient.clear(); token.clear(); })
          .finally(() => setRestoring(false));
      else setRestoring(false);
    }, 0);
    return () => clearTimeout(id);
  }, [gate]);

  if (!gate)      return <ConnectionGate ready={() => setGate(true)} />;
  if (restoring)  return <شاشة الاسترجاع />;
  if (!user)      return <LoginPage logged={(u) => { queryClient.clear(); setUser(u); }} />;
  return <AppShell user={user} exit={() => { queryClient.clear(); token.clear(); setUser(null); }} />;
}
```

| البوابة | الشرط | المكوّن |
| --- | --- | --- |
| 1. الاتصال | `!gate` | `ConnectionGate` في `Page/Auth/index.jsx` |
| 2. الاسترجاع | `restoring` | شاشة انتظار |
| 3. الدخول | `!user` | `LoginPage` في `Page/Auth/index.jsx` |
| 4. التطبيق | — | `AppShell` |

### تفاصيل تستحق الانتباه

| التفصيل | السبب |
| --- | --- |
| `restoring` يبدأ بـ`Boolean(token.get())` | بلا توكن لا شاشة انتظار أصلاً |
| `setTimeout(..., 0)` | يؤجّل الطلب لما بعد التصيير الأول — يمنع وميض الواجهة |
| `queryClient.clear()` عند الدخول والخروج | **حرج**: يمنع تسرّب بيانات مستخدم إلى جلسة مستخدم آخر على نفس الجهاز |
| `token.clear()` عند فشل `/auth/me` | التوكن منتهٍ أو الحساب معطّل |
| دالة تنظيف `clearTimeout` | لازمة مع `StrictMode` |

`ConnectionGate` يستدعي `GET /api/status` ويفحص الخادم وقاعدة البيانات والتخزين قبل
إظهار شاشة الدخول. الفائدة: خطأ الاتصال يظهر واضحاً بدل رسالة غامضة عند أول عملية.

## التوجيه — `src/Apihooks/route.jsx`

```jsx
export const tabRouteIds = [
  "dashboard", "tasks", "drive", "reports", "organization",
  "communications", "formal-correspondences", "circulars", "forms",
  "offices", "database", "hr-requests", "hr", "employees",
  "profile", "guide", "permissions", "notification",
];

export const router = createBrowserRouter([
  { path: "/",     element: <App /> },
  { path: "/:tab", element: <App /> },
]);
```

### توجيه غير معتاد — اقرأ هذا

مساران فقط، وكلاهما يصيّر `<App />` نفسه. **لا توجد مسارات فرعية لكل صفحة.**

الآلية الحقيقية في `src/Layout/AppShell.jsx`:

```jsx
const { tab } = useParams();
const view = tabRouteIds.includes(tab) ? tab : "dashboard";
```

يقرأ المعامل من الرابط، ويتحقق أنه ضمن القائمة البيضاء، ثم يصيّر الصفحة المقابلة
بشرط `if/else`. أي معامل غير معروف يعيد التوجيه إلى الجذر:

```jsx
useEffect(() => {
  if (tab && !tabRouteIds.includes(tab)) navigate("/", { replace: true });
}, [navigate, tab]);
```

| النتيجة | التفصيل |
| --- | --- |
| المزايا | الروابط قابلة للمشاركة، زر الرجوع يعمل، الحالة المشتركة تبقى حيّة عند التنقل |
| العيوب | لا تقسيم للحزمة حسب المسار — كل الصفحات تُحمَّل معاً |

> **عند إضافة تبويب يجب تعديل ثلاثة مواضع:** `tabRouteIds` هنا،
> شرط التصيير في `AppShell.jsx`، وعنصر في `json/navigation.json`.
> نسيان `tabRouteIds` يعني إعادة توجيه فورية إلى لوحة المعلومات.

`navigate("/")` للوحة المعلومات و`navigate("/tasks")` لغيرها — انظر
`navigateToView()` في `AppShell.jsx`.

## `src/Layout/AppShell.jsx` — الهيكل

538 سطراً. مسؤولياته:

### 1. بناء القائمة الجانبية

```jsx
const nav = useMemo(() =>
  navigationItems
    .filter((item) => {
      const canUsePermission = !item.permission
        || user.permissions?.includes(item.permission)
        || user.permissions?.includes(item.fallbackPermission);
      const canUseRole = !item.roles || item.roles.includes(user.role);
      return canUsePermission && canUseRole;
    })
    .map((item) => [item.id, t(item.labelKey), icons[item.icon]]),
  [t, user.permissions, user.role],
);
```

عنصر القائمة يظهر إن اجتاز فحصين: الصلاحية (أو البديلة) **و** الدور.
`fallbackPermission` موجود للتوافق مع أسماء الصلاحيات القديمة.

> **تذكير:** هذا الفلترة تحسين تجربة فقط. الحماية الحقيقية في مسارات الخادم.

### 2. الاشتراك في البث اللحظي

```jsx
const echo = createEcho();
if (!echo) return undefined;
const channel = echo.private(`user.${user.id}`);
const bump = (event) => {
  if (event.message?.unread_for_user)
    setUnreadMessageCountOverride((c) => (c ?? unreadQuery.data?.count ?? 0) + 1);
};
channel.listen(".message.created", bump);
channel.listen(".message.reply.created", bump);
```

`unreadMessageCountOverride` يزيد العدّاد فوراً بلا انتظار طلب جديد.
القيمة الفعلية:

```jsx
const unreadMessageCount = unreadMessageCountOverride ?? unreadQuery.data?.count ?? 0;
```

الأولوية للتجاوز المحلي، ثم قيمة الخادم، ثم صفر.

### 3. الحالة المشتركة عبر الصفحات

| الحالة | الغرض |
| --- | --- |
| `selected` | التقرير المفتوح في `ReportDrawer` |
| `selectedCircular` | التعميم المفتوح في `CircularDrawer` |
| `selectedFormPublication` | الفورم المفتوح في `ReusableFormModal` |
| `editing` + `reportForm` | تحرير تقرير في `ReportFormModal` |
| `toast` | رسالة التنبيه العائمة |
| `notice` | تفاصيل الإشعار المفتوح |

هذه الحالة في `AppShell` لا في الصفحات، لأن الإشعار قد يفتح تقريراً بينما المستخدم
في صفحة أخرى — انظر `openNotification()`:

```jsx
const detail = await notificationActions.notification.mutateAsync(item.id);
navigateToView("notification");
if (detail.source_type === "report" && detail.report) setSelected(detail.report);
if (detail.source_type === "circular" && detail.circular) setSelectedCircular(detail.circular);
if (detail.source_type === "form" && detail.custom_form_publication)
  setSelectedFormPublication(detail.custom_form_publication);
```

## المزوّدات

### `src/Provider/LanguageContext.jsx`

```jsx
const value = useMemo(() => ({
  lang,
  toggle: () => setLang((v) => (v === "ar" ? "en" : "ar")),
  t: (key, values = {}) => Object.entries(values).reduce(
    (text, [name, value]) => text.replace(`:${name}`, String(value)),
    translations[lang][key],
  ),
}), [lang]);

useEffect(() => language.set(lang), [lang]);
```

`language.set()` في `Api/storage.js` يحدّث `localStorage` و`document.documentElement`
معاً — فتبديل اللغة يقلب الاتجاه فوراً.

الاستهلاك:

```jsx
const { t, lang, toggle } = useLanguage();
t("welcome", { name: user.name })    // "مرحباً :name" ← "مرحباً أحمد"
```

`useLanguage()` يرمي خطأً إن استُخدم خارج المزوّد — يمنع أخطاء صامتة.

### `src/Provider/ConfirmContext.jsx`

نوافذ التأكيد قبل العمليات المدمّرة، بديل موحّد عن `window.confirm`.
