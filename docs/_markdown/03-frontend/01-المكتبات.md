## React 19 — ما يعنيه عملياً

| الميزة | الأثر |
| --- | --- |
| `StrictMode` | في التطوير **تُشغَّل التأثيرات مرتين** — تأكد أن `useEffect` قابل للتكرار |
| دوال التنظيف | إلزامية للاشتراكات والمؤقتات — انظر `AppShell.jsx` مع Echo |
| `createRoot` | واجهة التصيير الحديثة، مستخدمة في `main.jsx` |

مثال على التنظيف الصحيح من `src/Layout/AppShell.jsx`:

```js
return () => {
  echo.leave(`user.${user.id}`);
  echo.disconnect();
};
```

بدونه تتراكم اتصالات WebSocket عند كل إعادة تصيير.

## React Query 5 — لماذا لا `useState` + `useEffect`

| بدونها | معها |
| --- | --- |
| حالة تحميل وخطأ يدوية في كل صفحة | تأتي جاهزة من الـhook |
| إعادة الجلب يدوياً بعد كل تعديل | `invalidateQueries()` |
| طلبات مكررة لنفس البيانات | كاش مشترك بمفتاح |
| مسح البيانات عند الخروج | `queryClient.clear()` |

الإعداد في `src/Apihooks/queryClient.js`:

```js
export const queryClient = new QueryClient({
  defaultOptions: {
    queries: {
      staleTime: 1000 * 60,        // دقيقة قبل اعتبار البيانات قديمة
      retry: 1,                    // محاولة إعادة واحدة
      refetchOnWindowFocus: false, // لا إعادة جلب عند العودة للنافذة
    },
  },
});
```

`refetchOnWindowFocus: false` اختيار متعمّد — النظام إداري داخلي، والبيانات لا تتغير
كل ثانية، فإعادة الجلب المستمرة إزعاج وحمل بلا فائدة.

## Tailwind 4 — الفرق عن الإصدار 3

| الفرق | التفصيل |
| --- | --- |
| لا `tailwind.config.js` | الإعداد داخل CSS عبر `@theme` |
| لا PostCSS | `@tailwindcss/vite` يتكامل مباشرةً |
| استيراد واحد | `@import "tailwindcss";` في `src/index.css` |
| Preflight | **غير مفعّل** في هذا المشروع |

> **Preflight معطّل عمداً.** المشروع له ثيم قائم في `src/index.css` كُتب قبل إدخال
> Tailwind. تفعيل Preflight سيصفّر أنماط المتصفح ويغيّر المظهر بالكامل.
> Tailwind يُستخدم **تدريجياً في العناصر الجديدة فقط**.

## lucide-react — الأيقونات

```jsx
import { RefreshCw, LayoutDashboard } from "lucide-react";
<RefreshCw size={22} className="text-brand-500" />
```

`FrontEnd/json/navigation.json` يخزّن **اسم الأيقونة نصاً**:

```json
{ "id": "dashboard", "labelKey": "dashboard", "icon": "LayoutDashboard" }
```

و`AppShell.jsx` يحوّله إلى مكوّن. لذلك عند إضافة تبويب تأكد أن الاسم موجود فعلاً في
lucide، وإلا لن تظهر أيقونة.

## قبل إضافة أي حزمة

اسأل بالترتيب:

1. هل يمكن إنجازها بـ`fetch` أو React أو Tailwind؟
2. هل ستُستخدم في أكثر من مكان واحد؟
3. ما حجمها على الحزمة النهائية؟
4. هل تدعم RTL؟ **كثير من مكتبات الواجهة لا تدعمها جيداً** — وهذا سبب رئيسي
   لكتابة المكوّنات يدوياً في هذا المشروع.
