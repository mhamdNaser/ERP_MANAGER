## تعريف القائمة — `FrontEnd/json/navigation.json`

```json
{
  "id": "reports",
  "labelKey": "reports",
  "icon": "ClipboardList",
  "permission": "reports.view"
}
```

| الحقل | الغرض |
| --- | --- |
| `id` | يطابق المعرّف في `tabRouteIds` وشرط التصيير في `AppShell` |
| `labelKey` | مفتاح ترجمة في `i18n` |
| `icon` | اسم أيقونة من `lucide-react` — **نصاً** |
| `permission` | الصلاحية المطلوبة (اختياري) |
| `fallbackPermission` | صلاحية بديلة للتوافق مع الأسماء القديمة (اختياري) |
| `roles` | مصفوفة أدوار مسموحة (اختياري) |

المنطق في `AppShell.jsx`:

```js
const canUsePermission = !item.permission
  || user.permissions?.includes(item.permission)
  || user.permissions?.includes(item.fallbackPermission);
const canUseRole = !item.roles || item.roles.includes(user.role);
return canUsePermission && canUseRole;
```

## الفلاتر المتدرّجة حسب الصلاحية

نمط متكرر في `Page/Reports/index.jsx`:

| الفلتر | من يراه |
| --- | --- |
| التاريخ | الجميع |
| الموظف | رئيس القسم فما فوق |
| القسم | مدير الفرع فما فوق |
| الفرع | المدير العام ومدير قواعد البيانات |

الفلتر يظهر فقط إن كان له معنى في نطاق المستخدم — رئيس قسم لا يحتاج فلتر قسم لأنه
يرى قسمه فقط.
