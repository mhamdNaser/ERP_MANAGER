# متغيرات البيئة

## أين تُقرأ

| الطرف | الملف | من يقرؤه |
| --- | --- | --- |
| الباك أند | `BackEnd/.env` | Laravel عبر `config/*.php` |
| الفرونت أند | `FrontEnd/.env` | Vite عبر `import.meta.env` + `FrontEnd/vite.config.js` |

قالب الباك أند: `BackEnd/.env.example`.
الفرونت أند ليس له قالب مرفوع؛ الجدول أدناه هو المرجع.

> ملاحظة من `BackEnd/.env.example`: الملف الحقيقي يحتفظ بكتلتين `[LOCAL]` و`[SERVER]`
> وواحدة فقط غير معلّقة. لا تحذف الكتلة الأخرى — علّقها.

## متغيرات الباك أند

### التطبيق

| المتغير | القيمة الافتراضية | الأثر |
| --- | --- | --- |
| `APP_NAME` | `"CND Manager"` | يظهر في الوثائق المولّدة والبريد |
| `APP_ENV` | `local` | `production` يفعّل تحسينات ويقلل التفاصيل |
| `APP_KEY` | — | يولَّد بـ `php artisan key:generate`؛ بدونه لا يعمل التشفير |
| `APP_DEBUG` | `true` | عند `true` يضيف `exception`/`file`/`line`/`trace` إلى استجابة الخطأ في `BackEnd/bootstrap/app.php` — **أوقفه في الإنتاج** |
| `APP_URL` | `http://localhost` | أساس روابط `Storage::url()` |
| `APP_LOCALE` | `en` | اللغة الافتراضية قبل ترويسة `X-Language` |
| `APP_FALLBACK_LOCALE` | `en` | يُستخدم عند لغة غير مدعومة، انظر `BackEnd/app/Http/Middleware/SetLocale.php` |

### قاعدة البيانات

| المتغير | الأثر |
| --- | --- |
| `DB_CONNECTION` | `pgsql` في الإنتاج؛ `config/database.php` يجعل الافتراضي `sqlite` إن لم يُضبط |
| `DB_HOST` / `DB_PORT` | `127.0.0.1` / `5432` |
| `DB_DATABASE` | `cnd_manager` |
| `DB_USERNAME` / `DB_PASSWORD` | مستخدم التطبيق `cnd_app` — اتصال `pgsql` |
| `DB_OWNER_USERNAME` / `DB_OWNER_PASSWORD` | مالك المخطط — اتصال `pgsql_owner` |
| `DB_READONLY_USERNAME` / `DB_READONLY_PASSWORD` | قراءة فقط — اتصال `pgsql_readonly` |

الاتصالات الثلاثة معرّفة في `BackEnd/config/database.php`. التفاصيل في
`04-database/01-الاتصالات-والإعداد.md`.

### البث اللحظي (Reverb)

| المتغير | القيمة | الأثر |
| --- | --- | --- |
| `BROADCAST_CONNECTION` | `reverb` | يفعّل مشغّل Reverb |
| `REVERB_APP_ID` | `cnd-manager` | معرّف التطبيق |
| `REVERB_APP_KEY` | `cnd-local-key` | **يجب أن يطابق** `VITE_REVERB_APP_KEY` في الفرونت |
| `REVERB_APP_SECRET` | `cnd-local-secret` | سرّ الخادم، لا يوضع في الفرونت |
| `REVERB_HOST` / `REVERB_PORT` | `127.0.0.1` / `8080` | العنوان الذي يتصل به العميل |
| `REVERB_SCHEME` | `http` | `https` في الإنتاج |
| `REVERB_SERVER_HOST` / `REVERB_SERVER_PORT` | `127.0.0.1` / `8080` | العنوان الذي يستمع عليه الخادم نفسه |

### التخزين والطوابير والكاش

| المتغير | القيمة | الأثر |
| --- | --- | --- |
| `FILESYSTEM_DISK` | `local` | القرص الافتراضي؛ الملفات الخاصة تذهب إلى `storage/app/private` |
| `QUEUE_CONNECTION` | `database` | يتطلب جدول `jobs` (منشأ في الترحيلات) |
| `CACHE_STORE` | `database` | يتطلب جدول `cache`؛ يُستخدم لحفظ سبب إعادة التقرير |
| `SESSION_DRIVER` | `database` | جلسات الويب (الـAPI يعتمد التوكن لا الجلسة) |

### توليد الوثائق

| المتغير | القيمة | الأثر |
| --- | --- | --- |
| `LIBREOFFICE_BINARY` | `/snap/bin/libreoffice` | المحوّل الأساسي DOCX ← PDF على الخادم |
| `LOCAL_WORD_PDF_FALLBACK` | `true` | على ويندوز يستخدم Microsoft Word تلقائياً عند غياب LibreOffice |

يقرؤها `BackEnd/app/Modules/Communications/Services/DocxPdfConverter.php`.

## متغيرات الفرونت أند

| المتغير | إلزامي | الافتراضي | الأثر |
| --- | --- | --- | --- |
| `VITE_API_BASE_URL` | **نعم** | — | أساس كل الطلبات. `FrontEnd/src/config/environment.js` يرمي خطأً عند غيابه |
| `VITE_API_TIMEOUT_MS` | لا | `300000` | مهلة الطلب (5 دقائق) — كبيرة عمداً لأجل رفع/تنزيل الملفات |
| `VITE_REVERB_ENABLED` | لا | معطّل | يجب أن تكون `"true"` نصاً حرفياً وإلا `createEcho()` يعيد `null` |
| `VITE_REVERB_APP_KEY` | عند التفعيل | — | يطابق `REVERB_APP_KEY` |
| `VITE_REVERB_HOST` | لا | `window.location.hostname` | مضيف WebSocket |
| `VITE_REVERB_PORT` | لا | `8080` | منفذ WebSocket |
| `VITE_REVERB_SCHEME` | لا | `http` | `https` يفعّل `forceTLS` |
| `VITE_DEV_API_TARGET` | لا | `http://127.0.0.1:8000` | هدف الوكيل في التطوير، يُقرأ في `FrontEnd/vite.config.js` |
| `VITE_DEV_SERVER_HOST` | لا | `127.0.0.1` | مضيف خادم Vite |
| `VITE_DEV_SERVER_PORT` | لا | `5173` | منفذ خادم Vite |

### وكيل التطوير

`FrontEnd/vite.config.js` يضبط وكيلاً يحوّل كل ما يبدأ بـ`VITE_API_BASE_URL`
إلى `VITE_DEV_API_TARGET`. هذا يحلّ CORS في التطوير:

```
المتصفح ──► http://127.0.0.1:5173/api/reports
                     │  (وكيل Vite)
                     ▼
              http://127.0.0.1:8000/api/reports
```

عند استخدام الوكيل اضبط `VITE_API_BASE_URL=/api` (مسار نسبي)، وعند الاتصال المباشر
اضبطه على العنوان الكامل `http://127.0.0.1:8000/api`.

## أخطاء شائعة في الإعداد

| العَرَض | السبب |
| --- | --- |
| صفحة بيضاء + `Missing required environment variable: VITE_API_BASE_URL` | لم تنشئ `FrontEnd/.env` |
| المرفقات تُرجع 404 | لم تنفّذ `php artisan storage:link` |
| لا تصل الرسائل لحظياً | `VITE_REVERB_ENABLED` ليس `"true"` أو المفتاحان غير متطابقين |
| تغييرات `.env` لا تظهر | نفّذ `php artisan config:clear` |
| تغييرات `.env` الفرونت لا تظهر | أعد تشغيل `npm run dev` — Vite يقرأ البيئة عند الإقلاع فقط |
