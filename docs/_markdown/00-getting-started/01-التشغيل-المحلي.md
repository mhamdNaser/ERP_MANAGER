# التشغيل المحلي — خطوة بخطوة

## 1. المتطلبات

| المتطلب | الإصدار | ملاحظة |
| --- | --- | --- |
| PHP | 8.2 فأعلى | مطلوب في `BackEnd/composer.json` |
| Composer | 2.x | لتثبيت حزم الباك أند |
| Node.js | 20 فأعلى | Vite 8 يتطلب Node حديثاً |
| PostgreSQL Server | 14 فأعلى | **pgAdmin ليس خادماً** — هو واجهة إدارة فقط |
| LibreOffice أو Microsoft Word | — | لتحويل DOCX إلى PDF، انظر `02-backend/06-توليد-Word-وPDF.md` |

امتدادات PHP المطلوبة: `pdo_pgsql`, `zip`, `gd`, `mbstring`, `fileinfo`, `openssl`.
امتداد `zip` إلزامي لأن مولّد الوثائق `BackEnd/app/Services/Documents/DocxTemplateRenderer.php`
يفتح ملف DOCX كأرشيف ZIP.

## 2. تهيئة الباك أند

```powershell
cd BackEnd
composer install
copy .env.example .env
php artisan key:generate
```

### إنشاء قاعدة البيانات

السكربت الجاهز ينشئ القاعدة والمستخدمين الثلاثة:

```powershell
psql -U postgres -f scripts/postgres-provision.sql
```

| ما ينشئه السكربت | الغرض |
| --- | --- |
| قاعدة `cnd_manager` | قاعدة التطبيق |
| مستخدم `cnd_owner` | مالك المخطط، يستخدمه اتصال `pgsql_owner` |
| مستخدم `cnd_app` | قراءة/كتابة، الاتصال الافتراضي `pgsql` |
| مستخدم `cnd_readonly` | قراءة فقط، اتصال `pgsql_readonly` |

عدّل كلمات المرور في `BackEnd/.env` لتطابق ما وضعته في السكربت
(`DB_PASSWORD`, `DB_OWNER_PASSWORD`, `DB_READONLY_PASSWORD`).

### تشغيل الترحيلات والبذور

```powershell
php artisan migrate --seed
php artisan storage:link
```

- `migrate` ينفّذ ملفات `BackEnd/database/migrations/` بالترتيب الزمني.
- `--seed` يشغّل `BackEnd/database/seeders/DatabaseSeeder.php` الذي ينشئ الأدوار
  والصلاحيات وحسابات العرض.
- `storage:link` إلزامي — بدونه لن تعمل روابط المرفقات والوثائق العامة، لأن الموديلات
  تبني الروابط عبر `Storage::disk('public')->url(...)`.

### تشغيل الخادم

```powershell
php artisan serve --host=127.0.0.1 --port=8000
```

## 3. تهيئة الفرونت أند

```powershell
cd FrontEnd
npm install
```

أنشئ ملف `FrontEnd/.env` بالحد الأدنى:

```dotenv
VITE_API_BASE_URL=http://127.0.0.1:8000/api
VITE_API_TIMEOUT_MS=300000
VITE_REVERB_ENABLED=true
VITE_REVERB_APP_KEY=cnd-local-key
VITE_REVERB_HOST=127.0.0.1
VITE_REVERB_PORT=8080
VITE_REVERB_SCHEME=http
```

`VITE_API_BASE_URL` **إلزامي**: ملف `FrontEnd/src/config/environment.js` يرمي استثناءً
عند غيابه ولن يقلع التطبيق أصلاً.

```powershell
npm run dev -- --host 127.0.0.1 --port 5173
```

افتح `http://127.0.0.1:5173`.

## 4. تشغيل خادم البث اللحظي (Reverb)

مطلوب للرسائل الفورية فقط. النظام يعمل بدونه لكن بلا تحديث لحظي.

```powershell
cd BackEnd
php artisan reverb:start --host=127.0.0.1 --port=8080
```

عند توقّف Reverb لا يفشل إرسال الرسالة — يُسجَّل تحذير فقط ويكمل الطلب.
التفاصيل في `01-architecture/04-الزمن-الحقيقي-Reverb.md`.

## 5. ترتيب الإقلاع الكامل (ثلاث نوافذ)

```
نافذة 1:  cd BackEnd  → php artisan serve --host=127.0.0.1 --port=8000
نافذة 2:  cd BackEnd  → php artisan reverb:start --host=127.0.0.1 --port=8080
نافذة 3:  cd FrontEnd → npm run dev -- --host 127.0.0.1 --port 5173
```

عند فتح الواجهة تمرّ بثلاث بوابات متتالية:

```
   ┌──────────────────────┐
   │  ConnectionGate      │  يستدعي GET /api/status
   │  Page/Auth/index.jsx │  يتحقق من الخادم وقاعدة البيانات
   └──────────┬───────────┘
              │ نجح
              ▼
   ┌──────────────────────┐
   │  استرجاع الجلسة       │  إن وُجد cnd_token في localStorage
   │  App.jsx             │  يستدعي GET /api/auth/me
   └──────────┬───────────┘
              │ لا يوجد توكن أو فشل
              ▼
   ┌──────────────────────┐
   │  LoginPage           │  POST /api/auth/login
   │  Page/Auth/index.jsx │
   └──────────┬───────────┘
              │ نجح
              ▼
   ┌──────────────────────┐
   │  AppShell            │  التطبيق الكامل
   │  Layout/AppShell.jsx │
   └──────────────────────┘
```

## 7. بناء نسخة إنتاج

```powershell
cd FrontEnd
npm run build          # الناتج في FrontEnd/dist
npm run preview -- --host 127.0.0.1 --port 4173
```

على الباك أند قبل النشر:

```powershell
php artisan config:cache
php artisan route:cache
php artisan migrate --force
```
