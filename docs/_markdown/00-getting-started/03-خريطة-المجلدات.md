### داخل Modules

كل موديول يتبع نفس الهيكل (ليست كل الأجزاء موجودة في كل موديول):

```
Modules/<الاسم>/
├── Routes/api.php          المسارات — يُحمّل تلقائياً
├── Controllers/            استقبال الطلب وإرجاع الاستجابة
├── Requests/               التحقق من المدخلات (FormRequest)
├── Resources/              تشكيل المخرجات (JsonResource)
├── Services/               قواعد العمل
├── Repositories/
│   ├── Interfaces/         العقد
│   └── Eloquent/           التنفيذ
└── Providers/              ربط الواجهة بالتنفيذ في الحاوية
```

### تنظيم الصفحات

الصفحات البسيطة ملف واحد `Page/<الاسم>/index.jsx`.
الصفحات الكبيرة تُقسَّم إلى مجلد `components/` بجانب `index.jsx`:

| الصفحة | التقسيم |
| --- | --- |
| `Page/Drive/` | `index.jsx` + `components/DriveComponents.jsx` + `components/driveUtils.jsx` |
| `Page/Tasks/` | `index.jsx` + `useFocusTask.js` + `components/` (TaskComponents · TaskFilters · TaskCard · TaskStatusMenu · TaskBoardStats · taskFiltering · taskMeta · taskUtils) |
| `Page/Hr/` | `index.jsx` + 4 مكوّنات + `hrUtils.js` |
| `Page/FormalCorrespondences/` | `index.jsx` + 10 مكوّنات + `formalUtils.js` |

هذا يطبّق قاعدة **لا ملف مصدر يتجاوز 400 سطر** — انظر `07-guides/02-قواعد-التطوير.md`.
