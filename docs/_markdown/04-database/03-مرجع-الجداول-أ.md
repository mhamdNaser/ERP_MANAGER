| العمود | النوع | القيود | الوصف |

### الحالات

| الحالة | المعنى | من يراها |
| --- | --- | --- |
| `draft` | مسودة | الموظف |
| `department_review` | عند رئيس القسم | رئيس القسم |
| `branch_review` | عند مدير الفرع | مدير الفرع |
| `general_review` | عند المدير العام | المدير العام |
| `returned` | معادة للموظف | الموظف |
| `approved` | معتمدة نهائياً | المدير العام ومدير قواعد البيانات |

> `branch_id` و`department_id` تُلتقط لحظة الإنشاء ولا تتغير لو نُقل الموظف لاحقاً.
> هذا مقصود: التقرير يبقى منسوباً لموقع كتابته.

## `report_actions` — سجل انتقالات التقارير

الترحيل: `2026_06_12_000005_create_report_actions_table.php`

| العمود | النوع | الوصف |
| --- | --- | --- |
| `id` | bigint | PK |
| `report_id` | FK → `reports` | |
| `actor_id` | FK → `users` | من نفّذ |
| `action` | string | `submit` \| `forward_branch` \| `forward_general` \| `return` \| `approve` \| `updated` \| `updated_returned` |
| `from_status` | string | الحالة قبل |
| `to_status` | string | الحالة بعد |
| `note` | text, nullable | الملاحظة — إلزامية عند `return` |

> **سجل تدقيقي — لا يُعدَّل ولا يُحذف.** العلاقة في الموديل مرتّبة `latest()`.

> **سبب الإعادة لا يُحفظ هنا فقط.** يُحفظ نسخة في الكاش بمفتاح
> `reports:return-note:{id}` لمدة 14 يوماً، ويُحذف عند إعادة الإرسال.
> `ReportResource` يقرؤه ليعرضه للموظف.
