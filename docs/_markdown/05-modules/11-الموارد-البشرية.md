### حساب المدة في الخادم

```php
protected function passedValidation(): void
{
    if ($this->input('type') === 'departure' && $this->filled(['start_time', 'end_time'])) {
        $start = Carbon::createFromFormat('H:i', $this->input('start_time'));
        $end   = Carbon::createFromFormat('H:i', $this->input('end_time'));
```

## مسار الاعتماد

```php
public const STAGES = ['hr', 'gm'];
```

```
   الموظف
     │ ينشئ الطلب
     ▼
┌──────────────┐
│ pending_hr   │  الموارد البشرية
│ stage = hr   │
└──┬────────┬──┘
   │approve │reject
   ▼        └────────► rejected (نهائي)
┌──────────────┐
│ pending_gm   │  المدير العام
│ stage = gm   │
└──┬────────┬──┘
   │approve │reject
   ▼        └────────► rejected
┌──────────────┐
│  approved    │  + خصم الرصيد + توليد الوثيقة
│ stage = done │
└──────────────┘
```

> **لا محطة لرئيس القسم.** الترحيل `2026_07_29_000002_route_hr_requests_to_hr_first.php`
> ألغاها. الحالة `pending_head` باقية كقيمة افتراضية في الجدول لكنها غير مستخدمة.

> **إضافة محطة ثالثة = تعديل `STAGES`** (مع مواءمة `canDecide()` و`stageLabel()`).
> `nextStage()` يتنقل بالفهرس:
> ```php
> $index = array_search($stage, HrRequest::STAGES, true);
> return $index === false ? null : (HrRequest::STAGES[$index + 1] ?? null);
> ```

## النطاق — `HrAccessService`

**مختلف تماماً عن باقي النظام:** لا يعتمد الهرم التنظيمي بل عضوية قسم HR.

```php
public const HR_KEYWORDS = ['موارد بشرية', 'الموارد البشرية', 'human resources'];

public function hrDepartmentIds(): array
{
    return Department::query()
        ->where(fn ($q) => $q->where('code', 'HR')
            ->orWhere('name', 'like', '%موارد بشرية%') /* ... */)
        ->pluck('id')->all();
}

public function isHrStaff(?User $user): bool
{
    return $user->can('hr.manage')
        || ($user->department_id && in_array((int) $user->department_id, $this->hrDepartmentIds(), true));
}
```

> **قسم HR يُكتشف بالرمز `HR` أو باسم يطابق `HR_KEYWORDS`.** إعادة تسمية القسم بما
> لا يطابق أياً منهما **تُفقد موظفيه الوصول فوراً**. راجع الثابت عند نقل النظام.

### من يرى ومن يبتّ

```php
/** الاطلاع على الطلب حكرٌ على صاحبه والموارد البشرية والمدير العام. */
public function canView(?User $user, HrRequest $request): bool
{
    return (int) $request->user_id === (int) $user->id
        || $this->isHrStaff($user)
        || $user->role === 'general_manager';
}

public function canDecide(?User $user, HrRequest $request): bool
{
    if (! $user || ! $request->isOpen()) return false;

    return match ($request->stage) {
        'hr' => $this->isHrStaff($user),
        'gm' => $user->role === 'general_manager',
        default => false,
    };
}
```

> **رؤساء الأقسام ومدراء الفروع لا يرون طلبات موظفيهم.** التعليق في رأس الخدمة صريح.
> السبب: خصوصية الطلبات (إجازة مرضية مثلاً).

| الدالة | ترجع |
| --- | --- |
| `stageApprovers($request)` | المعنيّون بالمحطة الحالية — للإشعارات |
| `hrStaffQuery()` | موظفو قسم HR النشطون |
| `watchers()` | HR + المدير العام مجتمعين |
| `pendingForUser($user)` | ما ينتظر قراره |

## سير العمل — `HrWorkflowService::approve()`

```php
return DB::transaction(function () use ($request, $actor, $note) {
    $this->record($request, $actor, 'approve', $note);          // 1. سجل القرار

    $previousStage = $request->stage;
    $next = $this->nextStage($request->stage);
    $request->update([                                          // 2. الحالة
        'stage'      => $next ?: 'done',
        'status'     => $this->statusForStage($next),
        'decided_at' => $next ? null : now(),
    ]);
    $request = $request->fresh();

    if (! $next) {                                              // المحطة الأخيرة
        $this->consumeBalance($request);                        // 3. خصم الرصيد
        $this->documents->generate($request->load('user'), $actor);  // 4. الوثيقة
        $this->notify($request->user_id, 'الموافقة على طلبك', ...);
        $this->notifyWatchers($request, 'اعتماد طلب موظف', ..., [$request->user_id]);
    } else {
        $this->notifyStageOwners($request);                     // 5. إشعار المحطة التالية
        $this->notify($request->user_id, 'تقدّم طلبك خطوة',
            $request->reference_code . ' — وافقت ' . $this->stageLabel($previousStage)
            . ' وحُوّل إلى ' . $this->stageLabel($next) . '.');
    }

    return $request;
});
```

خمس مسؤوليات في معاملة واحدة. فشل أي واحدة يُلغي كلها.

### الرفض

```php
public function reject(HrRequest $request, User $actor, ?string $note = null): HrRequest
{
    $rejectedAt = $request->stage;
    $this->record($request, $actor, 'reject', $note);
    $request->update(['status' => 'rejected', 'stage' => 'done', 'decided_at' => now()]);
    // الرفض ينهي المسار ويعود إلى الموظف فوراً.
}
```

> **الرفض نهائي** — لا إعادة إلى محطة سابقة. الموظف ينشئ طلباً جديداً.
> (يختلف عن التقارير التي تُعاد للتعديل.)

### الإلغاء

`cancel()` — يلغي الطلب بلا قرار. متاح لصاحب الطلب ما دام مفتوحاً.

## الأرصدة

```php
public function consumeBalance(HrRequest $request): void
{
    if ($request->type !== 'leave' || $request->subtype !== 'annual' || ! $request->days) return;

    $balance = $this->balanceFor($request->user_id, (int) ($request->start_date?->format('Y') ?: now()->year));
    $balance->increment('used_days', $request->days);
}

public function balanceFor(int $userId, ?int $year = null): HrLeaveBalance
{
    return HrLeaveBalance::firstOrCreate(
        ['user_id' => $userId, 'year' => $year ?: now()->year],
        ['annual_entitlement' => 30, 'used_days' => 0],
    );
}
```

| القاعدة | التفصيل |
| --- | --- |
| **الإجازة السنوية وحدها تُخصم** | المرضية وغير المدفوعة والمهام لا تُخصم |
| **الخصم عند الاعتماد النهائي فقط** | لا عند الإنشاء ولا عند موافقة HR |
| السنة من `start_date` | إجازة ديسمبر تُخصم من رصيد سنتها لا سنة القرار |
| الاستحقاق الافتراضي | 30 يوماً — قابل للتعديل عبر `PUT /api/hr/balances/{employee}` |
| `remaining_days` | **سمة محسوبة** في الموديل لا عمود |

> **لا استرجاع للرصيد عند الإلغاء بعد الاعتماد.** إن احتجت ذلك أضف `restoreBalance()`.

### `GET /api/hr/requests` — لوحة HR والمدير العام

```php
abort_unless($isHrStaff || $isGeneralManager, 403, 'هذا القسم متاح للموارد البشرية والمدير العام.');

$requests = HrRequest::with(self::RELATIONS)
    ->when(! $isHrStaff, fn ($q) => $q->whereIn('status', ['pending_gm', 'approved', 'rejected']))
    ->when($request->string('type')->toString(),   fn ($q, $type) => $q->where('type', $type))
    ->when($request->string('status')->toString(), fn ($q, $status) => $q->where('status', $status))
    ->when($request->integer('user_id'),           fn ($q, $userId) => $q->where('user_id', $userId))
    ->latest()->get();
```

| المستخدم | يرى | يحصل على |
| --- | --- | --- |
| موظف HR | كل الطلبات في كل الحالات | الأرصدة + قائمة الموظفين (لأدوات الإدارة) |
| المدير العام | `pending_gm`, `approved`, `rejected` فقط | لا أدوات إدارة |

> المدير العام لا يرى `pending_hr` — لم تصل إليه بعد.
