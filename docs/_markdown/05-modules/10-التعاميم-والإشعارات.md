## النموذج متعدد المصادر

جدول `cnd_notifications` يحمل **أربعة مفاتيح اختيارية** للمصدر:

| العمود | يشير إلى |
| --- | --- |
| `report_id` | تقرير |
| `circular_id` | تعميم |
| `custom_form_id` | قالب فورم |
| `custom_form_publication_id` | نسخة نشر فورم |

`NotificationResource` يستنتج النوع:

```php
$sourceType = $this->report_id ? 'report'
    : ($this->circular_id ? 'circular'
    : ($this->custom_form_id ? 'form' : null));
```

ويرفق المورد الكامل عند تحميله:

```php
'source_type' => $sourceType,
'report'      => new ReportResource($this->whenLoaded('report')),
'circular'    => new CircularResource($this->whenLoaded('circular')),
'custom_form' => new CustomFormResource($this->whenLoaded('customForm')),
'custom_form_publication' => new CustomFormPublicationResource($this->whenLoaded('customFormPublication')),
```

> **`whenLoaded()` مهم:** قائمة الإشعارات لا تحمّل المصادر (خفيفة)، أما فتح إشعار
> واحد فيحمّل مصدره كاملاً. الحقل يظهر عند التحميل فقط.

## فتح الإشعار في الواجهة

`FrontEnd/src/Layout/AppShell.jsx`:

```jsx
const openNotification = async (item) => {
  const detail = await notificationActions.notification.mutateAsync(item.id);
  setNotice(detail);
  navigateToView("notification");
  setSelected(null); setSelectedCircular(null); setSelectedFormPublication(null);

  if (detail.source_type === "report" && detail.report)
    setSelected(detail.report);
  if (detail.source_type === "circular" && detail.circular)
    setSelectedCircular(detail.circular);
  if (detail.source_type === "form" && detail.custom_form_publication)
    setSelectedFormPublication(detail.custom_form_publication);

  setNotifications((items) => items.map((n) => (n.id === item.id ? detail : n)));
};
```

`source_type` يحدد أي درج أو نافذة تُفتح. تصفير الحالات الثلاث أولاً يمنع بقاء
درج سابق مفتوحاً.

> **الحالة في `AppShell` لا في الصفحة** — لأن الإشعار قد يفتح تقريراً بينما
> المستخدم في صفحة أخرى.

## من ينشئ الإشعارات

| المصدر | الملف | متى |
| --- | --- | --- |
| انتقال تقرير | `Modules/Reports/Repositories/Eloquent/ReportRepository.php` | كل انتقال |
| رسالة جديدة | `Modules/Communications/Repositories/Eloquent/CommunicationRepository.php` | إنشاء رسالة |
| رد على رسالة | نفسه | كل رد |
| تعميم جديد | نفسه | لكل مستلم |
| نشر فورم | `Modules/Forms/Services/CustomFormService.php` | `notifyRecipients()` |
| قرار HR | `Modules/Hr/Services/HrWorkflowService.php` | موافقة/رفض/تقدّم |
| محطة مراسلة | `Modules/Communications/Services/FormalTimelineService.php` | `notifyRecipients()` |

النمط الموحّد:

```php
CndNotification::create([
    'user_id' => $recipient->id,
    'title'   => __('messages.report_updated'),
    'message' => __('messages.report_waiting', ['title' => $report->title]),
    'report_id' => $report->id,          // اختياري
]);
```

> **الرسائل مترجمة عبر `__()`** لتصل بلغة المستخدم — تعتمد على `SetLocale`
> الذي قرأ ترويسة `X-Language`.

## التوجيه الدقيق للإشعارات

من `ReportRepository::transition()`:

```php
$recipients = $target === 'returned'
    ? User::whereKey($report->employee_id)                         // الموظف وحده
    : ($role ? User::role($role)
        ->when($role === 'department_head', fn ($q) => $q->where('department_id', $report->department_id))
        ->when($role === 'branch_manager',  fn ($q) => $q->where('branch_id', $report->branch_id))
        : null);

$recipients?->get()->each(fn ($r) => CndNotification::create([...]));
```

> **لا يُشعَر كل مدراء الأفرع** — المعني بالفرع فقط. طبّق هذا التضييق دائماً،
> وإلا صار مركز الإشعارات ضجيجاً يتجاهله الجميع.

## القراءة

```php
public function markAllRead(User $user): void   // POST /api/notifications/read-all
```

`useNotifications.js` يبطل الكاش بعد النجاح:

```js
const readAll = useMutation({
  mutationFn: api.readAllNotifications,
  onSuccess: () => queryClient.invalidateQueries({ queryKey: ["dashboard", "notifications"] }),
});
```

مع تعديل متفائل في `AppShell.jsx`:

```jsx
setNotifications((items) => items.map((n) => ({ ...n, read_at: n.read_at || new Date().toISOString() })));
```

الشارة تختفي فوراً والطلب يجري في الخلفية.

فتح إشعار واحد يعلّمه مقروءاً عبر `findFor()` في المستودع.

## في لوحة المعلومات

`SystemController::dashboard()`:

```php
$notifications = CndNotification::where('user_id', $request->user()->id)
    ->latest()->limit(6)->get()
    ->load(['report.employee', 'report.branch', 'report.department', 'circular.issuer']);
```

وعدّاد غير المقروء في بطاقات الانتباه:

```php
'unread_notifications' => CndNotification::where('user_id', $user->id)->whereNull('read_at')->count(),
```

## نقاط التوسّع

| ما تريد إضافته | كيف |
| --- | --- |
| مصدر إشعار جديد | عمود `<x>_id` + علاقة + فرع في `$sourceType` + معالجة في `openNotification()` |
| إشعار بالبريد | `Notifiable` مفعّل على `User` — أضف Notification class |
| بثّ لحظي للإشعارات | حدث جديد على نمط `MessageCreated` |
| تفضيلات الإشعارات | جدول `notification_preferences` + فحص قبل الإنشاء |
| تجميع الإشعارات المتشابهة | عمود `group_key` + دمج عند العرض |
| تنظيف الإشعارات القديمة | أمر مجدول يحذف المقروءة الأقدم من 90 يوماً |
| تقرير قراءة التعاميم | `circular_recipients.read_at` موجود — أضف شاشة |
