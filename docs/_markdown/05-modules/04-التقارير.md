### قاعدة الاختفاء

> عند تحويل رئيس القسم التقرير إلى مدير الفرع أو المدير العام، **يختفي من قائمته
> ومن قائمة الموظف**. السبب في `ReportAccessService`: النطاق يجمع الانتماء التنظيمي
> **مع الحالة**. رئيس القسم يرى `department_review` فقط.

## `ReportAccessService` — من يرى ماذا

```php
public function visibleTo(User $user): Builder
{
    $query = Report::query()->with(['employee:id,name,job_title', 'branch:id,name', 'department:id,name'])->latest();

    return match ($user->primaryRole()) {
        'database_manager' => $query,                                    // كل شيء
        'general_manager'  => $query->whereIn('status', ['general_review', 'approved']),
        'branch_manager'   => $query->where('branch_id', $user->branch_id)->where('status', 'branch_review'),
        'department_head'  => $query->where('department_id', $user->department_id)->where('status', 'department_review'),
        default            => $query->where('employee_id', $user->id)->whereIn('status', ['draft', 'returned']),
    };
}
```

| الدور | يرى |
| --- | --- |
| `database_manager` | كل التقارير في كل الحالات |
| `general_manager` | ما وصل إليه (`general_review`) وما اعتمده (`approved`) |
| `branch_manager` | تقارير فرعه في `branch_review` فقط |
| `department_head` | تقارير قسمه في `department_review` فقط |
| الموظف | تقاريره في `draft` و`returned` فقط |

`canManage()` يطبّق المنطق نفسه على سجل واحد.

## `ReportRepository::transition()` — قلب المنطق

```php
public function transition(User $user, Report $report, string $action, ?string $note = null): Report
{
    if (! $this->access->canManage($user, $report))
        throw ValidationException::withMessages(['report' => __('messages.report_forbidden')]);

    $this->ensureAllowedTransition($user, $report, $action, $note);

    $target = match ($action) {
        'submit' => 'department_review', 'forward_branch' => 'branch_review',
        'forward_general' => 'general_review', 'return' => 'returned', 'approve' => 'approved',
    };
    $role = match ($target) {
        'department_review' => 'department_head', 'branch_review' => 'branch_manager',
        'general_review' => 'general_manager', default => null,
    };

    DB::transaction(function () use (...) {
        $from = $report->status;
        $report->update(['status' => $target, 'current_reviewer_role' => $role,
                         'submitted_at' => $report->submitted_at ?? now()]);

        ReportAction::create(['report_id' => $report->id, 'actor_id' => $user->id,
            'action' => $action, 'from_status' => $from, 'to_status' => $target, 'note' => $note]);

        if ($action === 'return') Cache::put($this->returnNoteCacheKey($report), $note, now()->addDays(14));
        if ($action === 'submit') Cache::forget($this->returnNoteCacheKey($report));

        $recipients = $target === 'returned'
            ? User::whereKey($report->employee_id)
            : ($role ? User::role($role)
                ->when($role === 'department_head', fn ($q) => $q->where('department_id', $report->department_id))
                ->when($role === 'branch_manager',  fn ($q) => $q->where('branch_id', $report->branch_id))
                : null);

        $recipients?->get()->each(fn ($r) => CndNotification::create([...]));
    });

    return $report->fresh()->load(['employee', 'branch', 'department', 'actions']);
}
```

### نقاط مهمة

| النقطة | التفصيل |
| --- | --- |
| فحصان منفصلان | `canManage()` = "هل يخصّني؟" و`ensureAllowedTransition()` = "هل يجوز هذا الفعل؟" |
| `submitted_at ?? now()` | يُضبط **مرة واحدة** عند أول إرسال ولا يتغير |
| توجيه الإشعار | `User::role($role)` مُفلتَر بالقسم أو الفرع — لا يُشعَر كل مدراء الفروع |
| الإعادة | إشعار للموظف وحده |
| المعاملة | فشل أي خطوة يُلغي كل شيء |

## مصفوفة الانتقالات المسموحة

`ensureAllowedTransition()`:

| الدور | الحالة | الأفعال المسموحة |
| --- | --- | --- |
| `database_manager` | `draft` / `returned` | `submit` |
| | `department_review` | `forward_branch`, `forward_general`, `return` |
| | `branch_review` | `forward_general`, `return` |
| | `general_review` | `approve`, `return` |
| `general_manager` | `general_review` | `approve`, `return` |
| `branch_manager` | `branch_review` | `forward_general`, `return` |
| `department_head` | `department_review` | `forward_branch`, `forward_general`, `return` |
| الموظف | `draft` / `returned` | `submit` |

```php
if (! in_array($action, $allowed, true))
    throw ValidationException::withMessages(['action' => __('messages.report_forbidden')]);
```

> **رئيس القسم يستطيع التخطي إلى المدير العام** (`forward_general`) دون المرور
> بمدير الفرع. مقصود لتسريع الحالات التي لا تحتاج مراجعة الفرع.

> **بعد الاعتماد لا رجعة.** لا انتقال مسموح من `approved`، وزر الإعادة يتعطّل في الواجهة.

## سبب الإعادة — لماذا في الكاش

```php
if ($action === 'return')  Cache::put("reports:return-note:{$report->id}", $note, now()->addDays(14));
if ($action === 'submit')  Cache::forget("reports:return-note:{$report->id}");
```

يُقرأ في `ReportResource`:

```php
'return_note' => $this->status === 'returned' ? Cache::get("reports:return-note:{$this->id}") : null,
```

| السؤال | الجواب |
| --- | --- |
| لماذا لا عمود؟ | مؤقت بطبيعته — يُعرض للموظف ثم يُحذف عند إعادة الإرسال |
| هل يضيع؟ | **السبب الدائم محفوظ في `report_actions.note`** — الكاش نسخة عرض فقط |
| ماذا لو مُسح الكاش؟ | يختفي المربع التوضيحي، والسجل الكامل يبقى في `report_actions` |
| المتطلب | `CACHE_STORE=database` — جدول `cache` موجود في الترحيلات |

## تعديل التقرير المعاد

```php
public function updateReturned(User $user, Report $report, array $data): Report
{
    if ($user->primaryRole() !== 'database_manager'
        && ($report->employee_id !== $user->id || $report->status !== 'returned'))
        throw ValidationException::withMessages(['report' => __('messages.report_forbidden')]);

    DB::transaction(function () use ($report, $user, $data) {
        $from = $report->status;
        $report->update($data);
        ReportAction::create([..., 'action' => $from === 'returned' ? 'updated_returned' : 'updated', ...]);
    });
}
```

الموظف يعدّل تقريره **المعاد فقط**. مدير قواعد البيانات يعدّل أي تقرير في أي حالة.
كل تعديل يُسجَّل في `report_actions`.

## الإحصاءات

```php
public function statistics(User $user): array
{
    $visible = $this->access->visibleTo($user);
    return [
        'total'     => (clone $visible)->count(),
        'pending'   => (clone $visible)->whereIn('status', ['submitted','department_review','branch_review','general_review'])->count(),
        'returned'  => (clone $visible)->where('status', 'returned')->count(),
        'completed' => (clone $visible)->where('status', 'approved')->count(),
    ];
}
```

> `clone` إلزامي — بدونه تتراكم شروط `where` على الاستعلام نفسه وتفسد الأرقام التالية.
