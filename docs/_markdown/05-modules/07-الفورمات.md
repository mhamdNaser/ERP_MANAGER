## النموذج ذو الثلاث طبقات

```
CustomForm (القالب)              ← يبنيه مدير قواعد البيانات
    │
    ├── CustomFormField (الحقول)
    │
    └── CustomFormPublication (نسخة نشر)   ← ينشرها المدير أو الرئيس
             │       نطاق + جمهور + فترة
             │
             └── CustomFormSubmission (إجابة)   ← يعبّئها المستخدم
                      version + payload (JSON)
```

> **فصل القالب عن النشر مقصود:** الفورم نفسه يُنشر أكثر من مرة بنطاقات وجماهير
> وفترات مختلفة، والإجابات تُنسب إلى نسخة النشر لا إلى القالب.

## أنواع الحقول

`text` · `email` · `password` · `date` · `number` · `textarea` · `select` · `checkbox`

الحقل يحمل: `field_key` (المفتاح في `payload`)، `label`، `input_type`،
`options` (JSON للقوائم)، `placeholder`، `help_text`، `is_required`، `sort_order`.

قيد `UNIQUE(custom_form_id, field_key)` يمنع تكرار المفاتيح.

## النشر

```php
public function publish(CustomForm $form, User $issuer, array $payload): CustomFormPublication
{
    return DB::transaction(function () use ($form, $issuer, $payload) {
        $publication = CustomFormPublication::create([
            'custom_form_id' => $form->id,
            'issuer_id'      => $issuer->id,
            'scope'          => $payload['scope'] ?? $form->default_scope,
            'target_group'   => $this->normalizeTargetGroup($payload['target_group'] ?? $form->target_group),
            'branch_id'      => $scope === 'branch'     ? ($payload['branch_id'] ?? $issuer->branch_id) : null,
            'department_id'  => $scope === 'department' ? ($payload['department_id'] ?? $issuer->department_id) : null,
            'visible_from'   => Arr::get($payload, 'visible_from'),
            'visible_until'  => Arr::get($payload, 'visible_until') ?? (
                Arr::get($payload, 'duration_days')
                    ? now()->addDays((int) Arr::get($payload, 'duration_days'))
                    : ($form->default_duration_days ? now()->addDays((int) $form->default_duration_days) : null)
            ),
            'status'  => $payload['status'] ?? 'active',
            'message' => $payload['message'] ?? null,
        ]);

        $this->notifyRecipients($form, $publication, $issuer);
        return $publication->load([...]);
    });
}
```

| النقطة | التفصيل |
| --- | --- |
| القيم الافتراضية من القالب | النشر يرث ما لم يُحدَّد |
| `branch_id` / `department_id` | يُملأ حسب النطاق فقط، والباقي `null` |
| الافتراضي عند الغياب | فرع/قسم الناشر نفسه |
| `visible_until` | صريح، أو `duration_days`، أو `default_duration_days`، أو بلا انتهاء |
| `notifyRecipients()` | إشعار لكل من يطابق الجمهور |

## طبقات الرؤية الأربع

**افهم الفرق بينها قبل أي تعديل:**

### 1. `publicationVisibleTo()` — هل النشر ضمن نطاقي التنظيمي؟

```php
if (in_array($user->primaryRole(), ['database_manager', 'general_manager'], true)) return true;
if ($publication->scope === 'organization') return true;
if ($publication->scope === 'branch')     return (int) $user->branch_id === (int) $publication->branch_id;
if ($publication->scope === 'department') return (int) $user->department_id === (int) $publication->department_id;
return false;
```

### 2. `userMatchesPublication()` — هل أنا مخاطَب به فعلاً؟

```php
return $this->publicationVisibleTo($user, $publication)
    && $this->matchesTargetGroup($user, $publication->target_group);
```

النطاق **و** الجمهور معاً.

### 3. `accessiblePublication()` — هل يحق لي فتحه؟

```php
if ($user->primaryRole() === 'database_manager') return true;
if ($publication->issuer_id === $user->id) return true;                    // ناشره
if (in_array($user->primaryRole(), ['general_manager','branch_manager','department_head'], true))
    return $this->publicationVisibleTo($user, $publication);               // النطاق يكفي للمدراء
return $this->userMatchesPublication($user, $publication);                 // الجمهور شرط للموظف
```

> **الفرق الجوهري:** المدير يرى النشر إن كان في نطاقه **حتى لو لم يكن مخاطَباً به**.
> الموظف يراه فقط إن كان مخاطَباً به.

### 4. `accessibleTemplate()` — هل يحق لي تعديل القالب؟

```php
if (in_array($user->primaryRole(), ['database_manager', 'general_manager'], true)) return true;
return $form->creator_id === $user->id;
```

## `formsFor()` — ثلاث مجموعات

```php
[$templates, $assigned, $history] = $this->forms->formsFor($user);
```

| المجموعة | المحتوى | لمن |
| --- | --- | --- |
| `templates` | القوالب النشطة | مدير قواعد البيانات، المدير العام، مدير الفرع، رئيس القسم |
| `assigned` | نشرات موجّهة إليّ **ولم أعبّئها بعد** | الجميع |
| `history` | كل تعبئاتي السابقة | الجميع |

```php
$assigned = $publications->filter(function ($publication) use ($user) {
    if (! $this->userMatchesPublication($user, $publication)) return false;

    return ! CustomFormSubmission::query()
        ->where('custom_form_publication_id', $publication->id)
        ->where('user_id', $user->id)->exists();
});
```

> `assigned->count()` هو رقم "الفورمات غير المعبأة" في بطاقات الانتباه بلوحة المعلومات.

## التعبئة والنسخ

```php
public function submit(CustomFormPublication $publication, User $user, array $payload): CustomFormSubmission
{
    $version = (int) (CustomFormSubmission::where('custom_form_id', $publication->custom_form_id)
        ->where('user_id', $user->id)->max('version') ?? 0) + 1;

    return CustomFormSubmission::create([
        'custom_form_id' => $publication->custom_form_id,
        'custom_form_publication_id' => $publication->id,
        'user_id' => $user->id,
        'version' => $version,
        'payload' => $payload,
        'submitted_at' => now(),
    ]);
}
```

> **إعادة التعبئة تنشئ صفاً جديداً بنسخة أعلى — الإجابات السابقة لا تُحذف أبداً.**
> النسخة محسوبة على مستوى **القالب** لا النشر، فترقيم المستخدم متصل عبر كل النشرات.

## تحديث القالب — انتبه

```php
$form->fields()->delete();
$this->syncFields($form, $payload['fields'] ?? []);
```

> **تعديل القالب يحذف كل حقوله ويعيد إنشاءها.** المعرّفات تتغير.
> الإجابات المحفوظة تستخدم `field_key` نصاً في `payload`، فتبقى سليمة **ما دام
> المفتاح لم يتغيّر**. **لا تغيّر `field_key` لحقل له إجابات سابقة** — ستُقرأ فارغة.

## نقاط التوسّع

| ما تريد إضافته | كيف |
| --- | --- |
| نوع حقل جديد | `syncFields()` + مكوّن في `ReusableFormModal.jsx` + `FormBuilderModal.jsx` + `formValue()` في التصدير |
| حقول شرطية | عمود `conditions` (JSON) في `custom_form_fields` + منطق عرض في الواجهة |
| رفع ملف في الفورم | نوع `file` + تخزين المسار في `payload` |
| حقول محسوبة | عمود `formula` + تقييم في الواجهة |
| تذكير بالفورمات غير المعبأة | أمر مجدول يقرأ `assigned` وينشئ إشعارات |
| إغلاق تلقائي عند الانتهاء | فحص `visible_until` في `publicationVisibleTo()` |
| جمهور مخصص بقائمة أشخاص | جدول `publication_recipients` |
