## 1. فحص الصحة

`SystemController::health()` — ثلاث مراحل:

### أ. قاعدة البيانات

```php
try { DB::select('select 1'); }
catch (Throwable) { return response()->json([...], 503); }
```

الفشل يوقف الفحص فوراً ويرجع 503.

### ب. اختبار الكتابة على القرصين

```php
$probe = ".health/{$disk}-write-probe";
$contents = 'ok-' . Str::uuid();
$written = $filesystem->put($probe, $contents);
$readable = $written && $filesystem->get($probe) === $contents;
$filesystem->delete($probe);
```

**اختبار فعلي لا افتراضي**: يكتب ثم يقرأ ثم يقارن ثم يحذف، على `local` و`public`.

### ج. حدود الرفع

```php
'upload_limits' => [
    'upload_max_filesize' => ini_get('upload_max_filesize'),
    'post_max_size'       => ini_get('post_max_size'),
    'max_file_uploads'    => ini_get('max_file_uploads'),
],
```

> **قيمة عملية كبيرة:** عندما يشكو مستخدم من فشل رفع ملف، افتح `/api/status`
> واقرأ حدود PHP الفعلية بدل التخمين.

### الاستجابة

```json
{
  "status": "ready",
  "server": "متصل",
  "database": "متصلة",
  "connection": "pgsql",
  "storage": { "local": {"writable": true}, "public": {"writable": true} },
  "upload_limits": { "upload_max_filesize": "100M", "post_max_size": "100M", "max_file_uploads": "20" },
  "latency_ms": 12,
  "checked_at": "2026-08-02T10:14:22+00:00"
}
```

الرمز 200 إن كان كل شيء جاهزاً، و503 عند أي فشل.

> **لماذا مساران؟** التعليق في `Modules/Core/Routes/api.php` يوضّح: بعض حاجبات
> الإعلانات ومضادات الفيروسات تحجب المسارات التي تحوي `system/health` باعتبارها
> إشارات تتبّع، فيفشل الطلب في المتصفح قبل مغادرته (`ERR_BLOCKED_BY_CLIENT`).
> `/status` مرادف محايد، وهو ما تستخدمه الواجهة فعلياً (`api.health`).

## 2. تسجيل الدخول

```php
$user = User::with(['branch:id,name', 'department:id,name', 'office:id,name', 'roles:id,name'])
    ->where('email', $request->validated('email'))->where('is_active', true)->first();

if (! $user || ! Hash::check($request->validated('password'), $user->password))
    return response()->json(['message' => __('messages.invalid_credentials')], 422);

$plainToken = Str::random(64);
$user->update(['api_token' => hash('sha256', $plainToken)]);

return response()->json(['token' => $plainToken, 'user' => new UserResource($user)]);
```

| النقطة | التفصيل |
| --- | --- |
| `with([...:id,name])` | تحميل الأعمدة اللازمة فقط |
| `is_active` في الاستعلام | المعطّل لا يدخل |
| رسالة موحّدة | لا تفرّق بين بريد خاطئ وكلمة مرور خاطئة |
| 422 لا 401 | ليعرضها الفرونت في مكان أخطاء التحقق |
| `hash('sha256', ...)` | التوكن الخام لا يُخزَّن |

**الخروج** يضبط `api_token = null` — إبطال فوري على الخادم.

## 3. لوحة المعلومات

```php
return response()->json([
    'stats'           => $this->reports->statistics($request->user()),
    'analytics'       => $this->analytics->for($request->user()),
    'recent_reports'  => ReportResource::collection($this->reports->visibleTo($request->user(), 6)),
    'notifications'   => NotificationResource::collection($notifications),

```

### `DashboardAnalyticsService::for()`

```php
$reports = $this->reportAccess->visibleTo($user);      // نفس نطاق شاشة التقارير
$tasks   = $this->visibleTasks($user);
[, $assignedForms] = $this->forms->formsFor($user);
```

> **إعادة استخدام خدمات النطاق نفسها** — الرقم على اللوحة يطابق ما يراه المستخدم
> في الشاشة المتخصصة تماماً. لا منطق نطاق مكرّر.

#### المخرجات

| المفتاح | المحتوى |
| --- | --- |
| `report_trend` | 6 نقاط شهرية: `key`, `label`, `total`, `completed` |
| `task_trend` | 8 نقاط أسبوعية: `key`, `label`, `created`, `completed` |
| `status_distribution` | عدد التقارير في كل حالة من الست |
| `tasks` | `total`, `planned`, `in_progress`, `completed`, `urgent`, `due_this_week` |
| `attention` | `unread_notifications`, `assigned_forms`, `overdue_tasks`, `returned_reports` |

#### تقنية السلاسل المتصلة

```php
return collect(range(5, 0))->map(function (int $monthsAgo) use ($counts) {
    $month = now()->startOfMonth()->subMonths($monthsAgo);
    $items = $counts->get($month->format('Y-m'), collect());   // ← فارغة لا مفقودة
    return ['key' => ..., 'label' => ..., 'total' => $items->count(), ...];
})->values()->all();
```

> **الشهر الخالي يظهر بصفر لا يُحذف.** بدون هذا يقفز المخطط من مارس إلى مايو
> ويبدو مضلّلاً. الاختبار يتحقق: `assertJsonCount(6, 'analytics.report_trend')`.

#### نطاق المهام

```php
private function visibleTasks(User $user): Builder
{
    return match ($user->primaryRole()) {
        'general_manager', 'database_manager' => Task::query(),
        'branch_manager'  => Task::whereHas('department', fn ($q) => $q->where('branch_id', $user->branch_id)),
        'department_head' => Task::where('department_id', $user->department_id),
        default => Task::where(fn ($q) => $q->where('assignee_id', $user->id)->orWhere('creator_id', $user->id)),
    };
}
```

الموظف يرى ما أُسند إليه **أو** ما أنشأه.

#### بطاقات الانتباه

| البطاقة | الحساب |
| --- | --- |
| إشعارات غير مقروءة | `whereNull('read_at')` |
| فورمات غير معبأة | من `CustomFormService::formsFor()` |
| مهام متأخرة | `due_date < today()` وغير مكتملة أو ملغاة |
| تقارير معادة | `status = 'returned'` |

## 4. اللغة

### `LocaleController::setLocale()`

```php
abort_unless(in_array($lang, ['ar', 'en'], true), 404);

$payload = Cache::remember("translations_all_{$lang}_v1", 86400, function () use ($lang) {
    $admin = require resource_path("lang/{$lang}/admin.php");
    $messages = require resource_path("lang/{$lang}/messages.php");
    return array_merge($admin, $messages, [
        'admin' => $admin, 'messages' => $messages,
        '__meta' => ['language' => $lang, 'direction' => $lang === 'ar' ? 'RTL' : 'LTR'],
    ]);
});

return response()->json($payload)->header('Cache-Control', 'public, max-age=3600');
```

| النقطة | التفصيل |
| --- | --- |
| كاش 24 ساعة | ملفات اللغة لا تتغير وقت التشغيل |
| `_v1` في المفتاح | ارفعه بعد أي تعديل على ملفات اللغة لإبطال الكاش |
| `Cache-Control` ساعة | كاش على مستوى المتصفح أيضاً |
| مسطّح **و**متشعّب | `array_merge($admin, $messages)` + المفتاحان منفصلين — للتوافق |
| `__meta.direction` | يخبر العميل بالاتجاه |

> **بعد تعديل `resources/lang/*`** نفّذ `php artisan cache:clear` أو ارفع `_v1`
> إلى `_v2`، وإلا بقيت الترجمة القديمة 24 ساعة.
