## دليل المراسلة

```php
$users = User::with([...])->where('is_active', true)->whereKeyNot($actor->id)
    ->when($actor->primaryRole() !== 'general_manager' && ! $actor->office_id,
           fn ($q) => $q->where('role', '!=', 'general_manager'))->get();

return [
    'branches' => Branch::with(['departments' => fn ($q) => $q->with(['users' => ...])])->get(),
    'offices'  => Office::with(['users' => ...])->get(),
];
```

| القاعدة | الأثر |
| --- | --- |
| `is_active` | لا مراسلة مع حسابات معطّلة |
| `whereKeyNot($actor->id)` | لا يراسل نفسه |
| **حجب المدير العام** | لا يظهر إلا لمدير عام آخر أو لمن ينتمي إلى مكتب |

> **حماية المدير العام مقصودة:** لا يستطيع كل موظف مراسلته مباشرةً. المستثنى:
> منتسبو المكاتب (الديوان، الذاتية، القلم) — طبيعة عملهم تتطلب ذلك.

الدليل مُهيكل شجرياً (فروع ← أقسام ← موظفون، ومكاتب ← موظفون) للعرض المباشر.

## إنشاء رسالة

```php
$recipient = User::findOrFail($data['recipient_id']);

if ($recipient->id === $actor->id
    || ($recipient->primaryRole() === 'general_manager'
        && $actor->primaryRole() !== 'general_manager' && ! $actor->office_id))
    throw new AuthorizationException(__('messages.organization_forbidden'));

$message = Message::create($data + ['sender_id' => $actor->id, 'sender_read_at' => now()]);
CndNotification::create(['user_id' => $recipient->id, 'title' => __('messages.message_received'), 'message' => $data['subject']]);
$message->load([...]);
$this->broadcastSafely(fn () => MessageCreated::dispatch($message));
```

| النقطة | التفصيل |
| --- | --- |
| نفس قاعدة الدليل | مفروضة في الخادم لا في الواجهة فقط |
| `sender_read_at = now()` | رسالتك مقروءة بالنسبة لك فوراً |
| إشعار **و**بثّ | الإشعار دائم، البثّ لحظي — الأول لا يعتمد على الثاني |

## حالة القراءة المزدوجة

عمودان منفصلان: `sender_read_at` و`recipient_read_at`.

```php
public function markMessageRead(User $actor, Message $message): Message
{
    if (! in_array($actor->id, [$message->sender_id, $message->recipient_id]))
        throw new AuthorizationException(...);

    $message->forceFill($actor->id === $message->sender_id
        ? ['sender_read_at' => now()]
        : ['recipient_read_at' => now(), 'read_at' => $message->read_at ?? now()])->save();
}
```

عند الرد:

```php
$message->forceFill([
    'last_reply_at' => now(),
    'last_reply_sender_id' => $actor->id,
    'sender_read_at'    => $actor->id === $message->sender_id    ? now() : null,   // ★
    'recipient_read_at' => $actor->id === $message->recipient_id ? now() : null,   // ★
])->save();
```

> **الرد يجعل السلسلة غير مقروءة عند الطرف الآخر** — بتفريغ عمود قراءته.
> هذا يجعل السلسلة تتصرف كمحادثة لا كرسالة واحدة.

`read_at` القديم أُبقي للتوافق. الترحيل
`2026_06_16_000005_backfill_existing_message_read_state.php` عبّأ الأعمدة الجديدة
للسجلات السابقة.

### عدّاد غير المقروء

```php
return Message::where(fn ($q) => $q->where('sender_id', $actor->id)->orWhere('recipient_id', $actor->id))
    ->get()
    ->filter(fn (Message $message) => $this->isUnreadFor($message, $actor))
    ->count();
```

> **ملاحظة أداء:** يجلب كل الرسائل ثم يفلتر في PHP لأن المنطق يعتمد على أي طرف أنت.
> مقبول للأحجام الحالية، لكن **حوّله إلى استعلام SQL** إن تجاوز الجدول عشرات الآلاف.

## الحذف

```php
if ($message->sender_id !== $actor->id) throw new AuthorizationException(...);

if ($message->attachment_path) Storage::disk('public')->delete($message->attachment_path);
$message->replies->each(function (MessageReply $reply) {
    if ($reply->attachment_path) Storage::disk('public')->delete($reply->attachment_path);
});

return (bool) $message->delete();
```

| القاعدة | التفصيل |
| --- | --- |
| المرسل فقط | المستقبل لا يحذف من مصدره |
| حذف المرفقات | الرسالة **وكل ردودها** — لا ملفات يتيمة |
| حذف كامل | يختفي من الطرفين معاً |

## البثّ الآمن

```php
private function broadcastSafely(callable $callback): void
{
    try { $callback(); }
    catch (Throwable $exception) {
        Log::warning('Message realtime broadcast failed.', ['message' => $exception->getMessage()]);
    }
}
```

> **توقّف Reverb لا يُفشل إنشاء الرسالة.** تحذير في السجل والطلب يكمل.
> هذا هو النمط الصحيح لكل ميزة ثانوية.

التفاصيل الكاملة في `01-architecture/04-الزمن-الحقيقي-Reverb.md`.

## التعاميم — Circulars

بلاغ من إداري إلى مجموعة، بلا ردود.

### التحقق المزدوج من الجمهور

```php
$allowed = match ($role) {
    'department_head' => ['department_all', 'department_fixed_employees', 'department_contract_employees'],
    'branch_manager'  => ['branch_heads', 'branch_all', 'branch_fixed_employees', 'branch_contract_employees'],
    'general_manager' => ['general_branch_managers', 'general_management', 'general_all',
                          'general_fixed_employees', 'general_contract_employees'],
    default => [],
};

if (! in_array($audience, $allowed, true)) throw new AuthorizationException(...);
```

### مصفوفة الجمهور

| القيمة | المستلمون | لمن |
| --- | --- | --- |
| `department_all` | موظفو وفنيو قسمه | رئيس القسم |
| `department_fixed_employees` | المثبتون في قسمه | رئيس القسم |
| `department_contract_employees` | المتعاقدون في قسمه | رئيس القسم |
| `branch_heads` | رؤساء أقسام فرعه | مدير الفرع |
| `branch_all` | رؤساء وموظفو فرعه | مدير الفرع |
| `branch_fixed_employees` | المثبتون في فرعه | مدير الفرع |
| `branch_contract_employees` | المتعاقدون في فرعه | مدير الفرع |
| `general_branch_managers` | مدراء الأفرع | المدير العام |
| `general_management` | مدراء الأفرع ورؤساء الأقسام | المدير العام |
| `general_all` | الجميع عدا المدير العام | المدير العام |
| `general_fixed_employees` | كل المثبتين | المدير العام |
| `general_contract_employees` | كل المتعاقدين | المدير العام |

`applyCircularAudience()` يترجم القيمة إلى شروط استعلام.

### الإرسال

```php
return DB::transaction(function () use ($actor, $data, $query) {
    $circular = Circular::create($data + ['issuer_id' => $actor->id]);
    $ids = $query->pluck('id');
    $circular->recipients()->sync($ids);                    // pivot circular_recipients
    $ids->each(fn ($id) => CndNotification::create([
        'user_id' => $id, 'title' => __('messages.circular_received'),
        'message' => $data['title'], 'circular_id' => $circular->id,
    ]));
    return $circular->load('issuer:id,name,role');
});
```

> **قائمة المستلمين تُحسم لحظة الإنشاء وتُحفظ في pivot.** انضمام موظف جديد للقسم
> لاحقاً لا يجعله يرى تعاميم سابقة. هذا مقصود.

`circular_recipients.read_at` يتتبّع من قرأ.

### الرؤية

```php
Circular::where(fn ($q) => $q->where('issuer_id', $actor->id)
    ->orWhereHas('recipients', fn ($r) => $r->where('users.id', $actor->id)))->latest()->get();
```

المُصدِر أو المستلم فقط.

## نقاط التوسّع

| ما تريد إضافته | كيف |
| --- | --- |
| محادثة جماعية | جدول `message_participants` بدل `recipient_id` مفرد |
| مؤشر "يكتب الآن" | حدث بثّ جديد بلا حفظ في قاعدة البيانات |
| بحث في الرسائل | فهرس نصي كامل على `subject` و`content` |
| حذف من طرف المستقبل | عمود `deleted_by_recipient_at` بدل الحذف الفعلي |
| تعاميم بمرفقات متعددة | جدول `circular_attachments` |
| تأكيد قراءة التعميم | `circular_recipients.read_at` موجود — أضف شاشة تقرير |
| تحسين عدّاد غير المقروء | استبدل الفلترة في PHP باستعلام SQL |
