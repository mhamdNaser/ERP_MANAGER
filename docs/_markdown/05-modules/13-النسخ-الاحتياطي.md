## المسارات

| الطريقة | المسار | الوصف |
| --- | --- | --- |
| GET | `/api/database-backups` | قائمة النسخ |
| POST | `/api/database-backups/internal` | نسخة تُحفظ على الخادم |
| POST | `/api/database-backups/external` | نسخة تُنشأ وتُنزَّل فوراً |

عنصر القائمة `database` مقيّد بالدور نفسه في `navigation.json`.

## آلية النسخ

**النسخة ملف JSON** يحوي كل صفوف الجداول — **ليست `pg_dump`**.

```php
$payload = [
    'generated_at' => now()->toIso8601String(),
    'kind'         => $kind,
    'connection'   => DB::connection()->getName(),
    'database'     => DB::connection()->getDatabaseName(),
    'tables'       => $this->tableData(),
];

Storage::disk($disk)->put($path, json_encode($payload, JSON_PRETTY_PRINT | JSON_UNESCAPED_UNICODE));
```

اسم الملف: `cnd-backup-{Y-m-d_His}-{internal|external}.json`

> `JSON_UNESCAPED_UNICODE` يبقي العربية مقروءة في الملف بدل `\uXXXX`.

### الجداول المستثناة

```php
$exclude = ['migrations', 'sessions', 'jobs', 'job_batches', 'failed_jobs',
            'cache', 'cache_locks', 'password_reset_tokens', 'personal_access_tokens'];
```

جداول بنية تحتية لا بيانات عمل — استعادتها ضارّة لا مفيدة.

### اكتشاف الجداول حسب المحرّك

```php
$tables = match ($driver) {
    'pgsql'  => DB::select("select tablename from pg_tables where schemaname = 'public' order by tablename"),
    'sqlite' => DB::select("select name as tablename from sqlite_master where type = 'table' and name not like 'sqlite_%'"),
    'mysql'  => DB::select('select table_name as tablename from information_schema.tables where table_schema = database()'),
    default  => DB::select("select table_name as tablename from information_schema.tables where table_schema = current_schema()"),
};
```

يعمل على PostgreSQL والإنتاج، وعلى SQLite في الاختبارات.

## النوعان

| النوع | السلوك | الاستجابة |
| --- | --- | --- |
| `internal` | تُنشأ وتُحفظ في `storage/app/private/database-backups/` | 201 + بيانات وصفية |
| `external` | تُنشأ **وتُنزَّل فوراً** | `BinaryFileResponse` |

```php
public function external(): BinaryFileResponse
{
    $backup = $this->backups->createBackup('external');
    return response()->download($this->backups->absolutePath($backup['file_name']), ...);
}
```

> النسخة الخارجية تبقى محفوظة على الخادم أيضاً — الاسم يميّزها بلاحقة `-external`.

## التخزين

```php
private function disk(): string      { return env('BACKUP_STORAGE_DISK', 'local'); }
private function directory(): string { return trim((string) env('BACKUP_DIRECTORY', 'database-backups'), '/'); }
```

متغيران اختياريان في `.env`:

```dotenv
BACKUP_STORAGE_DISK=local
BACKUP_DIRECTORY=database-backups
```

القرص `local` (خاص) — لا تضع النسخ على `public` أبداً.

### مشكلة الصلاحيات — تعليق مهم في الشيفرة

```php
// Only create the directory when it is truly missing. Calling makeDirectory()
// on an existing directory re-applies the disk's (private => 0700) visibility
// via chmod, which both fails when the web user is not the owner and strips
// group access the deploy user needs. Storage::exists() reports files only,
// so probe the real path.
if (! is_dir(Storage::disk($disk)->path($directory))) {
    Storage::disk($disk)->makeDirectory($directory);
}
```

> **خلاصة العطل:** `makeDirectory()` على مجلد موجود يعيد تطبيق `chmod 0700`، فيفشل
> إن لم يكن مستخدم الويب هو المالك، ويسلب مستخدم النشر وصول المجموعة.
> و`Storage::exists()` لا يكشف المجلدات — لذلك `is_dir()` على المسار الحقيقي.
> **لا تُبسّط هذا الشرط.**

```php
Route::get('database-backups/{fileName}/download', [...])
    ->where('fileName', '[A-Za-z0-9._-]+');
```

القيد يمنع `/` و`..` — **إغلاق ثغرة اجتياز المسارات على مستوى التوجيه**

## القيود — اقرأ قبل الاعتماد عليها

| القيد | التفصيل |
| --- | --- |
| **لا استعادة** | لا يوجد مسار أو دالة للاستعادة. الملف بيانات فقط، والاستيراد يدوي. |
| **بلا بنية** | لا مخططات ولا فهارس ولا قيود — البيانات فقط. الاستعادة تتطلب قاعدة مُرحَّلة. |
| **الذاكرة** | `DB::table($table)->get()` يجلب الجدول كاملاً. قاعدة كبيرة قد تستنفد ذاكرة PHP. |
| **بلا ضغط** | JSON غير مضغوط — الملف كبير. |
| **بلا جدولة** | يدوي بالكامل، لا نسخ تلقائي. |
| **بلا ملفات** | `storage/app` غير مشمول — الملفات والوثائق ليست في النسخة. |

### البديل للنسخ الجادّ

```powershell
# نسخة كاملة بالبنية
pg_dump -U cnd_owner -d cnd_manager -F c -f backup.dump

# الاستعادة
pg_restore -U cnd_owner -d cnd_manager -c backup.dump

# ملفات التخزين
tar -czf storage.tar.gz BackEnd/storage/app
```

> **الميزة الحالية مناسبة للقطات سريعة قبل عملية محفوفة بالمخاطر.**
> لا تعتمد عليها كاستراتيجية نسخ احتياطي للإنتاج.

## نقاط التوسّع

| ما تريد إضافته | كيف |
| --- | --- |
| **الاستعادة** | مسار `POST /database-backups/{file}/restore` + خدمة تفرّغ الجداول وتعيد الإدراج داخل معاملة |
| **النسخ المجدول** | أمر artisan + `routes/console.php` مع `->daily()` + مهمة نظام تشغيل |
| **الضغط** | `gzencode()` قبل الحفظ + فك عند التنزيل |
| **`pg_dump` الحقيقي** | `Symfony\Process` على نمط `DocxPdfConverter` |
| **شمول الملفات** | ZIP يضم JSON + `storage/app` |
| **النسخ التزايدي** | فلترة بـ`updated_at > آخر نسخة` |
| **تنظيف تلقائي** | حذف النسخ الأقدم من N يوماً في الأمر المجدول |
| **تنبيه عند الفشل** | إشعار أو بريد للمسؤول |
| **معالجة الذاكرة** | `chunk()` بدل `get()` وكتابة تدفقية للملف |
