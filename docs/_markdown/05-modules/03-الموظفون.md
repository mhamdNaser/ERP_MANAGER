## `UserResource` — العقد الأهم

`app/Modules/Employees/Resources/UserResource.php` — يُستخدم في:
تسجيل الدخول، `/auth/me`، قائمة الموظفين، الملف الشخصي، وداخل `ReportResource`.

```php
$role = $this->getRoleNames()->first() ?? $this->role;

return [
    'id' => $this->id, 'name' => $this->name, 'email' => $this->email,
    'role'  => $role,
    'roles' => $this->getRoleNames(),
    'permissions' => $this->getAllPermissions()->pluck('name'),      // ★
    'job_title' => $this->job_title,
    'employee_number' => $this->employee_number,
    'employment_type' => $this->employment_type,
    'branch_id' => $this->branch_id, 'department_id' => $this->department_id,
    'office_id' => $this->office_id,
    'branch' => $this->whenLoaded('branch'),
    'department' => $this->whenLoaded('department'),
    'office' => $this->whenLoaded('office'),
    'is_active' => $this->is_active,
    'digital_signature_path' => $this->digital_signature_path,
    'digital_signature_url' => $this->digital_signature_path
        ? Storage::disk('public')->url($this->digital_signature_path) : null,
    'can_manage_digital_signature' =>
        in_array($role, ['department_head','branch_manager','general_manager'], true)
        || filled($this->office_id),
    'address' => $this->whenLoaded('address'),
    'family_details' => $this->whenLoaded('familyDetails'),
    'personal_details' => $this->whenLoaded('personalDetails'),
];
```

| الحقل | لماذا يهمّ |
| --- | --- |
| `permissions` | **يبني القائمة الجانبية كلها** في `AppShell.jsx` عبر `navigation.json` |
| `can_manage_digital_signature` | منطق محسوب مرة واحدة — الواجهة لا تكرّره |
| `whenLoaded()` | العلاقات تظهر عند تحميلها فقط — يمنع N+1 |
| `password`, `api_token` | **لا يظهران** — في `$hidden` وغير مذكورين هنا |

## التوقيع الرقمي

`EmployeeController::updateSignature()`:

```php
abort_unless($this->canManageSignature($user), 403, 'لا تملك صلاحية إنشاء توقيع رقمي.');

$data = $request->validate(['signature_data' => ['required', 'string']]);

if (! preg_match('/^data:image\/png;base64,/', $data['signature_data']))
    abort(422, 'صيغة التوقيع غير صحيحة.');

$raw = base64_decode(Str::after($data['signature_data'], ','), true);
if ($raw === false || strlen($raw) < 100)
    abort(422, 'التوقيع فارغ أو غير صالح.');

if ($user->digital_signature_path)
    Storage::disk('public')->delete($user->digital_signature_path);   // حذف القديم

$path = 'users/signatures/user-' . $user->id . '-' . uniqid() . '.png';
Storage::disk('public')->put($path, $raw);
$user->update(['digital_signature_path' => $path]);
```

| الفحص | يمنع |
| --- | --- |
| `canManageSignature()` | من لا يوقّع كتباً رسمية |
| `preg_match` على PNG | صيغة غير مدعومة (المحرك يدرج PNG فقط) |
| `base64_decode(..., true)` | الوضع الصارم يرفض base64 غير صالح |
| `strlen($raw) < 100` | لوحة توقيع فارغة |
| حذف القديم | تراكم ملفات يتيمة |

من يملك التوقيع:

```php
in_array($user->primaryRole(), ['department_head', 'branch_manager', 'general_manager'], true)
|| filled($user->office_id);
```

رؤساء الأقسام ومدراء الفروع والمدير العام، **وكل من ينتمي إلى مكتب** (الديوان مثلاً).

> التوقيع يُدرج في الكتب المولّدة عبر `SignatureImage` — انظر
> `02-backend/06-توليد-Word-وPDF.md`.

## كلمة المرور

### تعيينها من الإدارة

```php
$data = $request->validate(['password' => ['required', 'string', 'min:8', 'confirmed']]);
$this->employees->resetPassword($request->user(), $employee, $data['password']);
```

`confirmed` يتطلب حقل `password_confirmation` مطابقاً.
**لا تُطلب كلمة المرور القديمة** — هذا مسار إداري لمن يملك `employees.update`.

### التشفير

`app/Models/User.php` يضبط `'password' => 'hashed'` في `casts()`.
الإسناد يشفّر تلقائياً — **لا تستدعِ `Hash::make()` يدوياً**.

## أثر حذف الموظف

| السجل | السلوك |
| --- | --- |
| تقاريره | **تُحذف** (`cascadeOnDelete`) |
| ملفاته في Drive | **تُحذف** (`cascadeOnDelete` على `uploader_id`) |
| مهامه المسندة | تبقى بـ`assignee_id = null` |
| مهامه المنشأة | **تُحذف** (`cascadeOnDelete` على `creator_id`) |
| رسائله | **تُحذف** |
| بياناته الإضافية | **تُحذف** |
| سجل حركات المهام | **يبقى** — `actor_id` يصبح `null` والاسم محفوظ في `task_title` |

> **الحذف مدمّر وواسع الأثر.** فكّر في `is_active = false` بدلاً منه للموظفين
> المغادرين — يحفظ التاريخ ويمنع الدخول (الميدلوير يفحص `is_active`).

## نطاق الرؤية

`EmployeeRepository::all()` يستخدم `OrganizationScopeService::employees()`:

| الدور | يرى |
| --- | --- |
| `general_manager` / `database_manager` | كل الموظفين |
| `branch_manager` | موظفي فرعه |
| `department_head` | موظفي قسمه |
| غيرهم | نفسه فقط |

عنصر القائمة `employees` مقيّد بالدور في `navigation.json`:

```json
{ "id": "employees", "roles": ["general_manager", "database_manager"] }
```

> **لاحظ التفاوت:** رئيس القسم يملك `employees.view` و`employees.update` لكن لا يرى
> التبويب. يصل إلى موظفيه من شاشة الهيكل التنظيمي بدلاً منه. هذا اختيار تصميمي واعٍ.
