# التخزين والملفات

## قرصان لا أكثر

`BackEnd/config/filesystems.php`:

| القرص | المسار الفيزيائي | الوصول |
| --- | --- | --- |
| `local` | `BackEnd/storage/app/private/` | عبر الخادم فقط، بعد فحص الصلاحية |
| `public` | `BackEnd/storage/app/public/` | مباشرةً من المتصفح عبر الرابط الرمزي |

الرابط الرمزي يُنشأ بـ:

```powershell
php artisan storage:link
```

ينشئ `BackEnd/public/storage` ← `BackEnd/storage/app/public`.
**بدونه تُرجع كل روابط المرفقات 404.**

### قاعدة الاختيار

```
هل يجوز لأي شخص يملك الرابط أن يفتح الملف؟
   │
   ├── نعم  ──►  قرص public
   │             المرفقات، الوثائق المولّدة، التواقيع، الملفات المنشورة
   │
   └── لا   ──►  قرص local
                 ملفات Drive الخاصة، النسخ الاحتياطية، الملفات المؤقتة
```

## خريطة المسارات

### قرص `local` — خاص

```
storage/app/private/
├── drive/
│   └── users/{user_id}/            ملفات المستخدم ومجلداته الفيزيائية
│       └── {اسم المجلد}/            مجلدات فرعية حقيقية
├── backups/                        نسخ قاعدة البيانات
├── libreoffice/                    ملف تعريف LibreOffice (ضروري للتحويل)
└── tmp/                            ملفات مؤقتة (QR، تواقيع محوّلة)
```

### قرص `public` — منشور

```
storage/app/public/
├── communications/
│   ├── messages/                   مرفقات الرسائل
│   ├── message-replies/            مرفقات الردود
│   └── circulars/                  مرفقات التعاميم
├── formal-correspondences/         وثائق المراسلات المولّدة
├── hr-requests/
│   └── generated/{Y}/{m}/{d}/      وثائق طلبات HR
├── signatures/                     التواقيع الرقمية
└── drive-public/                   مرآة الملفات المنشورة من Drive
```

> **التنظيم الزمني** `generated/{Y}/{m}/{d}/` يمنع تراكم آلاف الملفات في مجلد واحد،
> ويسهّل الأرشفة والحذف بحسب الفترة. اتبعه في أي وثائق جديدة.

## نمط رفع المرفقات

المتكرر في `Modules/Communications/Controllers/CommunicationController.php`:

```php
if ($request->hasFile('attachment')) {
    $file = $request->file('attachment');
    $data['attachment_path'] = $file->store('communications/messages', 'public');
    $data['attachment_name'] = $file->getClientOriginalName();
    $data['attachment_mime'] = $file->getClientMimeType();
    $data['attachment_size'] = $file->getSize();
}
```

أربعة أعمدة ثابتة في كل جدول له مرفق:

| العمود | المصدر | الغرض |
| --- | --- | --- |
| `attachment_path` | `store()` | المسار المخزَّن — اسم عشوائي |
| `attachment_name` | `getClientOriginalName()` | الاسم الأصلي للعرض والتنزيل |
| `attachment_mime` | `getClientMimeType()` | تحديد طريقة العرض |
| `attachment_size` | `getSize()` | العرض والإحصاء |

`store()` يولّد اسماً عشوائياً — يمنع تصادم الأسماء وتخمين المسارات.
الاسم الأصلي محفوظ منفصلاً للعرض.

الرابط يُحسب في الموديل عبر `$appends`:

```php
protected $appends = ['attachment_url'];

public function getAttachmentUrlAttribute(): ?string
{
    return $this->attachment_path ? Storage::disk('public')->url($this->attachment_path) : null;
}
```

## Drive — النموذج الأعقد

`Modules/Drive/Controllers/DriveController.php` (776 سطراً).

### الفرق الجوهري عن المرفقات

Drive **ينشئ مجلدات فيزيائية حقيقية ويحفظ الملفات بأسمائها الأصلية**، ليتمكن مدير
النظام من تصفح `storage/app/private/drive/users/{id}/` من نظام التشغيل ويرى نفس ما
يراه المستخدم في الواجهة.

### حدود الرفع

```php
private const MAX_UPLOAD_FILES = 100;              // ملف في الطلب الواحد
private const MAX_UPLOAD_FILE_KILOBYTES = 102400;  // 100 ميغابايت للملف
private const MAX_UPLOAD_TOTAL_BYTES = 1073741824; // 1 غيغابايت إجمالاً
```

> هذه حدود التطبيق. حدود PHP نفسها (`upload_max_filesize`, `post_max_size`,
> `max_file_uploads`) قد تكون أقل — يعرضها `GET /api/status` في حقل `upload_limits`
> لتشخيص المشكلة بسرعة.

### تسلسل الرفع

```php
// 1. التحقق من الحجم الإجمالي
$incomingSize = collect($request->file('files'))->sum(fn ($file) => $file->getSize());
abort_if($incomingSize > self::MAX_UPLOAD_TOTAL_BYTES, 422, '...');

// 2. نطاق المؤسسة حكر على مدير قواعد البيانات
if ($data['scope'] === 'organization') {
    abort_unless($user->primaryRole() === 'database_manager', 403);
}

// 3. الوراثة من المجلد الأب
$scope = $folder?->scope ?? $data['scope'];
$departmentId = $folder?->department_id ?? ($data['department_id'] ?? $user->department_id);

// 4. فحص الوصول للقسم
abort_unless($departmentId && $this->canAccessDepartment($user, $departmentId), 403);

// 5. فحص الحصة
$this->ensureQuotaAllowsUpload($user, $incomingSize);

// 6. الحفظ باسم فريد
$storedName = $this->uniqueName('local', $directory, $uploaded->getClientOriginalName());
$storedPath = $uploaded->storeAs($directory, $storedName, 'local');

// 7. النشر التلقائي إن كان المجلد منشوراً
if ($folder?->public_token) { $this->publishFile($file); }
```

### الوراثة — قاعدة مهمة

الملف **يرث نطاق المجلد الأب وقسمه وحالة نشره**. رفع ملف في مجلد منشور ينشره تلقائياً.
هذا مقصود ليتصرف Drive كنظام ملفات حقيقي.

### تكرار الأسماء

`uniqueName()` يضيف `(2)`, `(3)` عند التكرار — كما في ويندوز. **لا يكتب فوق ملف موجود أبداً.**

### النشر العام — مساران

| الرابط | الشكل | المميزات |
| --- | --- | --- |
| `public_url` | `/api/public-files/{token}` | توكن عشوائي قابل للإلغاء، يمرّ بالخادم |
| `direct_url` | رابط ثابت على `drive-public/` | يعمل من أي برنامج خارجي، بنية مجلدات مطابقة |

عند النشر تُنشأ **مرآة فعلية** في `storage/app/public/drive-public` بنفس بنية المجلدات
والأسماء. إلغاء النشر يحذف النسخة العامة فقط ويُبقي الأصل الخاص.

### حصص التخزين

جدول `role_drive_quotas` — حصة لكل دور:

| المسار | الغرض |
| --- | --- |
| `GET /api/drive-role-quotas` | قراءة الحصص |
| `PUT /api/drive-role-quotas` | تعديلها |

`ensureQuotaAllowsUpload()` يفحص قبل كل رفع.

### التنزيل والمعاينة

| المسار | الدالة | الاستجابة |
| --- | --- | --- |
| `GET /api/drive-files/{file}/download` | `download()` | `BinaryFileResponse` — تنزيل |
| `GET /api/drive-files/{file}/preview` | `preview()` | `StreamedResponse` — عرض داخل المتصفح |

كلاهما يفحص الصلاحية في الخادم قبل التسليم. الملفات في `local` لا تُخدَم مباشرةً أبداً.

## النسخ الاحتياطي — `Modules/Database/Services/DatabaseBackupService.php`

| الدالة | الغرض |
| --- | --- |
| `listBackups()` | قائمة النسخ مع بياناتها الوصفية |
| `createBackup(string $kind)` | إنشاء نسخة: `internal` أو `external` |
| `delete(string $fileName)` | حذف نسخة |
| `pathFor()` / `absolutePath()` / `exists()` | مساعدات المسار |
| `downloadName()` | اسم الملف عند التنزيل |

النسخ في `storage/app/private/backups/` — قرص `local` لأنها بيانات حساسة.

المسار محمي بقيد على شكل الاسم في `Modules/Database/Routes/api.php`:

```php
->where('fileName', '[A-Za-z0-9._-]+')
```

يمنع `../` و`/` — إغلاق ثغرة اجتياز المسارات على مستوى التوجيه.

## فحص صحة التخزين

`Modules/Core/Controllers/SystemController.php::health()` يختبر الكتابة فعلياً:

```php
$probe = ".health/{$disk}-write-probe";
$contents = 'ok-' . Str::uuid();
$written = $filesystem->put($probe, $contents);
$readable = $written && $filesystem->get($probe) === $contents;
$filesystem->delete($probe);
```

يكتب ثم يقرأ ثم يحذف على كلا القرصين. النتيجة في `GET /api/status`:

```json
{
  "status": "ready",
  "storage": { "local": {"writable": true}, "public": {"writable": true} },
  "upload_limits": { "upload_max_filesize": "100M", "post_max_size": "100M" }
}
```

عند فشل أي قرص يرجع 503 وتتوقف الواجهة عند بوابة الاتصال — تشخيص فوري قبل ظهور
أخطاء غامضة عند أول رفع.

## قواعد عند التعامل مع الملفات

| القاعدة | السبب |
| --- | --- |
| لا تضع ملفاً حساساً على `public` | يصبح متاحاً لأي شخص يملك الرابط |
| احفظ الاسم الأصلي منفصلاً | المسار المخزَّن عشوائي |
| افحص الصلاحية قبل التسليم | حتى مع مسار غير قابل للتخمين |
| نظّف الملفات المؤقتة | `@unlink()` بعد الاستخدام مباشرةً |
| قيّد شكل أسماء الملفات في المسارات | `->where(...)` يمنع اجتياز المسارات |
| نظّم المجلدات زمنياً | يمنع التراكم ويسهّل الأرشفة |
| احذف الملف عند حذف السجل | وإلا تتراكم ملفات يتيمة |
