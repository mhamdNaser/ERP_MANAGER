## ما الجديد

### 1. الترقيم والبحث في الخادم

قوائم الهيكل التنظيمي الثلاث — الأفرع والأقسام والموظفون — كانت تُجلب كاملةً
في كل فتحة للشاشة وتُعرض دفعةً واحدة. صارت **خمسةً في الصفحة**، والتقسيم
والبحث يجريان في قاعدة البيانات لا في المتصفح.

| المسار | جديد؟ | ملاحظة |
| --- | --- | --- |
| `GET /api/organization` | لا | يعيد القوائم **كاملة** كما كان — تحتاجها القوائم المنسدلة |
| `GET /api/organization/branches` | **نعم** | `search`, `per_page`, `page` |
| `GET /api/organization/departments` | **نعم** | الفلاتر نفسها |
| `GET /api/employees` | لا | بلا `per_page` يعيد الكل كما كان؛ ومعها يُرقّم |

> **لماذا بقي `/organization` كاملاً؟** لأن نموذج تحرير القسم يحتاج كل الأفرع في
> قائمته المنسدلة، وشريط فلاتر الموظفين يحتاج كل الأفرع والأقسام. ترقيمه كان
> سيترك المستخدم يختار من خمسة أفرع فقط.

البحث في كل قائمة:

| القائمة | الحقول |
| --- | --- |
| الأفرع | الاسم · الرمز |
| الأقسام | الاسم · الرمز · **اسم الفرع** |
| الموظفون | الاسم · البريد · المسمى الوظيفي · الرقم الذاتي |

المقارنة عبر `LOWER(…) LIKE` لا `ILIKE`: الأولى تعمل على PostgreSQL وSQLite معاً
(الاختبارات على SQLite)، والثانية حكرٌ على PostgreSQL. العربية لا تتأثر بـ`LOWER`،
والرموز اللاتينية (`OP26` مقابل `op26`) تصير غير حسّاسة لحالة الأحرف.

`per_page` مسقوف بـ100 كي لا يجرّ عميلٌ الجدول كاملاً بطلب واحد.

### 2. فلاتر الموظفين

شريط مطويّ فوق الجدول: **الفرع · القسم · الدور · نوع التوظيف · الحالة**.

- الفلاتر مخفيّة حتى تُطلب كي لا تزاحم الجدول، وزرّها يحمل عدّاد ما هو مفعَّل.
- المفعَّل منها يظهر كرقائق قابلة للإزالة تحت الشريط — فلا يحتار أحد لماذا
  الجدول شبه فارغ.
- «مسح الفلاتر» يعيد الكل دفعةً واحدة.
- كل فلتر يُطبَّق في الخادم، ويعيدك إلى الصفحة الأولى: الصفحة الخامسة من نتيجةٍ
  جديدة قد لا تكون موجودة.

> الفلاتر **تُضيّق** نطاق المستخدم ولا توسّعه — نطاقه مطبَّق قبلها في
> `OrganizationScopeService`، فرئيس القسم لا يرى غير قسمه مهما فلتر.

### 3. رقم الإصدار تحت الشعار

يظهر `v1.2.0` أسفل اسم الإدارة في القائمة الجانبية. مصدره ملف `VERSION` في جذر
المشروع — نفسه الذي يوسمه `scripts/version.ps1` — يُحقن وقت البناء عبر
`vite.config.js`، فلا يُكتب الرقم في مكانين فيفترقا.

## الترقية

```powershell
git fetch --tags
git checkout v1.2.0

cd BackEnd
composer install
php artisan route:cache      # مساران جديدان
php artisan config:cache
php artisan cache:clear

cd ..\FrontEnd
npm install
npm run build                # يلتقط رقم الإصدار من VERSION
```

> `route:cache` لازم: المساران الجديدان لن يُعرفا بكاش مسارات قديم.
