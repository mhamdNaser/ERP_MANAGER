## التشغيل والإقلاع

| العَرَض | السبب | الحل |
| --- | --- | --- |
| صفحة بيضاء + `Missing required environment variable: VITE_API_BASE_URL` | لا يوجد `FrontEnd/.env` | أنشئه واضبط `VITE_API_BASE_URL` |
| الواجهة عالقة على بوابة الاتصال | `/api/status` يفشل | افحص أن Laravel يعمل وأن العنوان صحيح |
| `could not connect to server` | PostgreSQL متوقف | شغّل خدمة PostgreSQL (pgAdmin ليس خادماً) |
| `password authentication failed` | كلمات المرور غير متطابقة | وحّد `.env` مع `scripts/postgres-provision.sql` |
| `database does not exist` | لم يُنفَّذ سكربت التهيئة | `psql -U postgres -f scripts/postgres-provision.sql` |
| تغييرات `.env` لا تظهر (باك) | كاش الإعدادات | `php artisan config:clear` |
| تغييرات `.env` لا تظهر (فرونت) | Vite يقرأ البيئة عند الإقلاع | أعد تشغيل `npm run dev` |
| `/api/status` يرجع 503 | قاعدة البيانات أو التخزين | اقرأ حقل `storage` في الاستجابة |

## المصادقة والصلاحيات

| العَرَض | السبب | الحل |
| --- | --- | --- |
| 401 على كل الطلبات | التوكن مفقود أو منتهٍ | افحص `localStorage.cnd_token` وسجّل الدخول |
| 401 بعد تعطيل حساب | `is_active = false` جزء من استعلام المصادقة | مقصود — فعّل الحساب |
| 401 في اختبار | حفظت الخام وأرسلت الهاش | احفظ `hash('sha256','x')` وأرسل `'x'` |
| خروج مفاجئ | تسجيل دخول من جهاز آخر | توكن واحد لكل مستخدم — سلوك مقصود |
| 403 على مسار واحد | صلاحية ناقصة | افحص `RolePermissionSeeder` وشاشة الصلاحيات |
| صلاحية مُنحت ولا تعمل | كاش spatie | `forgetCachedPermissions()` أو `php artisan cache:clear` |
| صلاحية جديدة لا تظهر للمستخدم | الواجهة حمّلتها عند الدخول | أعد تحميل الصفحة |
| صلاحية اختفت بعد بذرة | `syncPermissions` استبدل القائمة | أضفها إلى `$roles` في البذرة |
| موظف HR فقد الوصول | اسم/رمز القسم لا يطابق | أعد `code='HR'` أو اسماً يحوي "موارد بشرية" |
| الديوان فقد الوصول للمراسلات | رمز المكتب ليس `REGISTRY` | أعد الرمز أو اسماً يحوي "ديوان" |

## التقارير

| العَرَض | السبب |
| --- | --- |
| التقرير اختفى من قائمة رئيس القسم | حوّله — النطاق يجمع الانتماء **مع الحالة**. سلوك مقصود |

## توليد Word و PDF

| العَرَض | السبب | الحل |
| --- | --- | --- |

## الواجهة

| العَرَض | السبب | الحل |
| --- | --- | --- |
| التبويب يعيد التوجيه للوحة | المعرّف ليس في `tabRouteIds` | أضفه في `Apihooks/route.jsx` |
| عنصر القائمة لا يظهر | الصلاحية أو الدور | افحص `navigation.json` و`user.permissions` |
| الأيقونة لا تظهر | الاسم غير موجود في lucide | تحقّق من الاسم |
| الواجهة تنكسر بالإنجليزية | خصائص فيزيائية | استبدل `ml-*` بـ`ms-*` |
| نص يظهر `undefined` | مفتاح ناقص في `en` | وحّد المفاتيح بين `ar` و`en` |
| نص لا يُترجم | مكتوب مباشرة في JSX | استبدله بـ`t()` |
| `LanguageProvider missing` | `useLanguage()` خارج المزوّد | تأكد أن المكوّن داخل `<LanguageProvider>` |
| الواجهة لا تتحدث بعد حفظ | نسيان `invalidateQueries` | أضفه في `onSuccess` |
| بيانات مستخدم سابق تظهر | نقص `queryClient.clear()` | **لا تحذفه من `App.jsx`** |
| الاتجاه يومض عند التحميل | ضبط `dir` بعد التصيير | يُضبط في `main.jsx` قبل `createRoot` |
| البحث لا يجد موظفاً موجوداً | فرق همزة أو تشكيل بين المكتوب والمخزّن | مرّر الطرفين على `normalizeText()` قبل المقارنة |
| مهمة تستحق اليوم تظهر «متأخرة» | `new Date("YYYY-MM-DD")` يُفسَّر UTC | قارن مفاتيح نصية عبر `toDateKey()` — استخدم `isOverdue()` |
| فلتر يُفرغ اللوحة بعد تبديل القسم | معرّفات المكلّفين والتصنيفات مرتبطة بالقسم | صفّر الفلاتر عند التبديل كما في `Page/Tasks/index.jsx` |
| المؤشرات العلوية تناقض عدد البطاقات | المؤشرات تقرأ القائمة الأصلية لا المصفّاة | مرّر القائمة بعد التصفية إلى مكوّن المؤشرات |

## البناء (Vite)

| العَرَض | السبب | الحل |
| --- | --- | --- |
| `[MISSING_EXPORT] "X" is not exported by "y.js"` مع أن التصدير موجود | ملفان بالاسم نفسه يختلفان في حالة الأحرف فقط (`TaskFilters.jsx` و`taskFilters.js`)، ونظام ملفات ويندوز غير حسّاس لها فيلتقط الاستيراد بلا لاحقة الملف الخطأ | غيّر أحد الاسمين بأكثر من حالة الأحرف (`taskFiltering.js`) |
| `npm run dev` يعمل والبناء يفشل | خادم التطوير يحلّ المسارات بترتيب مختلف عن البناء | لا تعتمد على ترتيب الحل — أبقِ الأسماء متمايزة |
| تحذير `chunks are larger than 500 kB` | الحزمة صفحة واحدة بلا تقسيم | تحذير قائم ومقبول حالياً — ليس خطأ بناء |

## قاعدة البيانات

| العَرَض | السبب | الحل |
| --- | --- | --- |
| `Target [XRepositoryInterface] is not instantiable` | المزوّد غير مسجّل | أضفه إلى `bootstrap/providers.php` |
| `permission denied for schema public` | صلاحيات ناقصة | `GRANT CREATE ON SCHEMA public TO cnd_app` |
| جدول جديد لا يراه `cnd_readonly` | `ALTER DEFAULT PRIVILEGES` غير مضبوط | نفّذه أو امنح يدوياً |
| نص عربي مشوّه | ترميز غير UTF8 | أعد إنشاء القاعدة بـ`ENCODING 'UTF8'` |
| الاختبار ينجح والإنتاج يفشل | فرق SQLite/PostgreSQL | تجنّب SQL خاصاً بمحرّك |
| `dropColumn` يفشل | العمود له مفتاح أجنبي | `dropConstrainedForeignId()` |
| أرقام الإحصاءات خاطئة | نقص `clone` على الاستعلام | `(clone $query)->count()` |

## أدوات التشخيص

```powershell
# الباك أند
php artisan route:list --path=api        # المسارات
php artisan migrate:status               # الترحيلات
php artisan db:show                      # الاتصال والجداول
php artisan pail                         # السجلات لحظياً
php artisan optimize:clear               # مسح كل الكاش
php artisan tinker                       # صدفة تفاعلية

# الفرونت أند
npm run lint
npm run build

# قاعدة البيانات
psql -U cnd_owner -d cnd_manager -c "\dt"
```

### تتبّع خطأ 500

```
1. اقرأ error_id من الاستجابة
2. ابحث عنه في السجل:
   Select-String -Path BackEnd/storage/logs/laravel.log -Pattern "<error_id>"
3. اقرأ الاستثناء والملف والسطر
```

### فحص صلاحيات مستخدم

```php
php artisan tinker

$u = App\Models\User::where('email','head@cnd.local')->first();
$u->primaryRole();
$u->getRoleNames();
$u->getAllPermissions()->pluck('name');
$u->can('reports.view');
```

### إعادة بناء الأدوار والصلاحيات

```powershell
php artisan db:seed --class=RolePermissionSeeder
php artisan cache:clear
```

> آمن على قاعدة فيها بيانات — لا يلمس المستخدمين ولا السجلات.
> **لكنه يمسح أي صلاحية مُنحت لدور خارج البذرة.**

## لا تفعل هذا في الإنتاج

| الأمر | لماذا |
| --- | --- |
| `php artisan migrate:fresh` | يحذف كل الجداول والبيانات |
| `php artisan db:wipe` | يحذف كل الجداول |
| `APP_DEBUG=true` | تسريب مسارات وأصناف وشيفرة |
| `php artisan db:seed` كاملاً | ينشئ بيانات تجريبية فوق الحقيقية |
| تعديل جدول مباشرة بـSQL | لا يُسجَّل في الترحيلات — يضيع عند إعادة البناء |
