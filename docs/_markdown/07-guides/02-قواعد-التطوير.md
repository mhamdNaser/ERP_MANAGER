## 2. أين يوضع الكود

| ما تكتبه | الملف |
| --- | --- |
| فحص شكل حقل | `Modules/*/Requests/` |
| فحص ملكية سجل | `Modules/*/Services/*ScopeService.php` |
| قاعدة عمل أو انتقال حالة | `Modules/*/Services/` |
| استعلام معقّد | `Modules/*/Repositories/Eloquent/` |
| تحديد الحقول الظاهرة | `Modules/*/Resources/` |
| علاقة أو `cast` أو سمة محسوبة | `app/Models/` |
| فرض صلاحية | `Modules/*/Routes/api.php` |
| منطق مشترك بين موديولين | `app/Services/` أو خدمة الموديول المالك |

**القاعدة:** إذا احتوى المتحكم على `if` تفحص دوراً أو حالة، فمكانها خدمة.

## 3. التسمية

| العنصر | النمط | مثال |
| --- | --- | --- |
| الموديل | مفرد PascalCase | `DriveFile` |
| الجدول | جمع snake_case | `drive_files` |
| المتحكم | `<الاسم>Controller` | `AssetController` |
| الطلب | `<الفعل><الاسم>Request` | `StoreAssetRequest` |
| المورد | `<الاسم>Resource` | `AssetResource` |
| الخدمة | `<الاسم><الغرض>Service` | `AssetScopeService` |
| المستودع | `<الاسم>Repository` | `AssetRepository` |
| الصلاحية | `<المورد>.<الفعل>` | `assets.manage` |
| صفحة الفرونت | `Page/<الاسم>/index.jsx` | `Page/Assets/index.jsx` |
| مفتاح الترجمة | `<البادئة>_<الوصف>` | `asset_holder` |
| مكوّن الواجهة | PascalCase بلاحقة `.jsx` | `TaskFilters.jsx` |
| ملف منطق مجاور | camelCase بلاحقة `.js`، **متمايز عن اسم المكوّن بأكثر من حالة الأحرف** | `taskFiltering.js` لا `taskFilters.js` |
| الترحيل | `YYYY_MM_DD_00000N_وصف` | `2026_08_10_000001_create_assets_table` |

## 4. الأمان

| القاعدة | السبب |
| --- | --- |
| افرض الصلاحية في المسار **والـRequest** | حاجزان لا واحد |
| افرض النطاق في الخادم لا في الواجهة | الـAPI مكشوف للاستدعاء المباشر |
| استخدم `primaryRole()` لا `$user->role` | يحترم أدوار spatie |
| استدعِ `forgetCachedPermissions()` بعد أي تعديل صلاحيات | وإلا لا تُطبَّق |
| لا تضع بيانات حساسة على قرص `public` | متاحة لأي شخص يملك الرابط |
| قيّد شكل المعاملات النصية في المسارات | `->where('fileName', '[A-Za-z0-9._-]+')` |
| `escapeHtml()` على كل قيمة مستخدم في التصدير | منع حقن HTML |
| `APP_DEBUG=false` في الإنتاج | يمنع تسريب المسارات والأصناف |
| افحص الصلاحية قبل تسليم أي ملف | حتى مع مسار غير قابل للتخمين |
| لا تسرّب سجلاً خارج النطاق عند التعديل | افحص الحالة الحالية **والحالة بعد التعديل** |

## 5. قاعدة البيانات

| القاعدة | التفصيل |
| --- | --- |
| `up()` و`down()` كلاهما يعمل | جرّب `migrate` ثم `rollback` |
| لا Eloquent داخل الترحيلات | الموديل يتغير؛ الترحيل يجب أن يبقى صالحاً |
| `chunkById()` لتعبئة البيانات | لا تحمّل آلاف الصفوف |
| `cascadeOnDelete` أو `nullOnDelete` صراحةً | فكّر في أثر الحذف |
| افهرس ما يُفلتَر به | `status`, `type`, المفاتيح الأجنبية |
| لا SQL خاص بمحرّك | الاختبار SQLite والإنتاج PostgreSQL |
| العمليات متعددة الجداول في `DB::transaction` | اتساق البيانات |
| `clone` على الاستعلام قبل إعادة استخدامه | وإلا تتراكم شروط `where` |

## 6. الواجهة

من `FrontEnd/STYLEGUIDE.md`:

| القاعدة | التفصيل |
| --- | --- |
| **لا حركة** | لا `animate-*` ولا `transition-*` ولا `backdrop-blur` |
| **لا ظلال زخرفية** | العمق من `border border-line` |
| **نصف قطر واحد** | `rounded` (4px) |
| **لا تدرّجات** | ولا توهّج ولا زخارف |
| **خصائص منطقية** | `ms-*` لا `ml-*`، `start-*` لا `left-*` |
| **رموز الثيم** | `bg-surface` لا `bg-white` |
| **الأولّيات أولاً** | `btn btn-primary` لا أصناف مركّبة |
| **كل نص عبر `t()`** | لا نص مكتوب مباشرة |
| **جرّب اللغتين** | RTL و LTR |

## 7. React

| القاعدة | السبب |
| --- | --- |
| بيانات الخادم في React Query لا `useState` | يمنع الحالة المكررة |
| `invalidateQueries` بعد كل طفرة | وإلا لا تتحدث الواجهة |
| مفاتيح الاستعلام مصفوفات هرمية | `["scope", "sub"]` |
| `enabled` على الاستعلامات المشروطة بصلاحية | يمنع 403 بلا داعٍ |
| دالة تنظيف لكل `useEffect` باشتراك | `StrictMode` يشغّلها مرتين |
| `queryClient.clear()` عند تبديل المستخدم | **حرج أمنياً** |
| `useMemo` للاشتقاق الثقيل | يمنع إعادة الحساب |

## 8. الترجمة

| القاعدة | التفصيل |
| --- | --- |
| أضف في ملف الجزء لا في `translations.js` | يمنع التعارض بين المطوّرين |
| نفس المفاتيح في `ar` و`en` | مفتاح ناقص ← `undefined` |
| بادئة النطاق للمفاتيح الجديدة | `drive_`, `task_`, `hr_` |
| أعد استخدام المشترَكة | `save`, `cancel`, `delete`, `close`… |
| **لا تترجم قيم الـAPI** | `'approved'` قيمة بيانات لا نص عرض |
| `tr()` خارج React، `t()` داخلها | لا سياق React في `Api/*.js` |

## 9. الأخطاء

| الحالة | الأسلوب |
| --- | --- |
| فشل تحقق أو قاعدة عمل | `ValidationException::withMessages([...])` ← 422 |
| صلاحية ناقصة | `abort_unless(..., 403)` |
| عطل بنية تحتية | `RuntimeException` ← 500 مع `error_id` |
| فشل ميزة ثانوية | `Log::warning()` وتابع — لا تُفشل العملية الأساسية |

> **الاستثناء:** إن ترك الفشل البيانات غير متسقة، أفشل المعاملة كاملة.

## 11. ما لا يجوز

| ✗ | السبب |
| --- | --- |
| إخفاء زر في الواجهة كحماية وحيدة | الـAPI مكشوف |
| `fetch` مباشر في مكوّن | يفقد الترويسات والمهلة ومعالجة الأخطاء |
| نص مكتوب مباشرة في JSX | يكسر الترجمة |
| `ml-*` / `left-*` | يكسر RTL |
| `Hash::make()` على كلمة المرور | `casts()` تشفّرها — تشفير مزدوج |
| موديل Eloquent في ترحيل | يكسر إعادة البناء من الصفر |
| صلاحية في البذور فقط | الإنتاج لا يعيد تشغيل البذور |
| `migrate:fresh` على بيانات حقيقية | يحذف كل شيء |
| `APP_DEBUG=true` في الإنتاج | تسريب معلومات |
| رفع حزمة لحل مسألة بسيطة | المشروع يميل لقلّة الاعتماديات |
| توسيع ملف متجاوز للحد | استخرج بدل ذلك |
| إرجاع `Collection` من خدمة نطاق | يمنع الفلترة اللاحقة |
