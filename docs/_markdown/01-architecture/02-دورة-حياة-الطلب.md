# دورة حياة الطلب — تتبّع كامل

هذا الملف يتتبع طلباً واحداً حقيقياً من ضغطة الزر حتى ظهور النتيجة، ذاكراً كل ملف يمرّ به.
المثال: **رئيس قسم يوافق على تقرير ويحوّله إلى مدير الفرع**.

## تفصيل كل محطة

### [3] طبقة HTTP — `FrontEnd/src/Api/http.js`

الترويسات المضافة في كل طلب:

| الترويسة | المصدر | الغرض |
| --- | --- | --- |
| `Authorization: Bearer <token>` | `Api/storage.js` ← `localStorage.cnd_token` | المصادقة |
| `X-Language` | `Api/storage.js` ← `localStorage.LANGUAGE` | لغة رسائل الخادم |
| `Content-Type: application/json` | يُحذف تلقائياً إذا كان الجسم `FormData` | |
| `Accept: application/json` | ثابت | يجبر Laravel على استجابة JSON |

المهلة عبر `AbortController` مضبوطة من `VITE_API_TIMEOUT_MS` (افتراضياً 5 دقائق).

الدوال الأربع المتاحة:

| الدالة | الاستخدام |
| --- | --- |
| `request()` | الطلبات العادية، ترجع JSON |
| `requestBlob()` | تنزيل ملف بلا مؤشر تقدّم |
| `requestBlobProgress()` | تنزيل مع مؤشر تقدّم (XHR) — يستخدمه أرشيف Drive |
| `requestUpload()` | رفع مع مؤشر تقدّم (XHR) — يستخدمه رفع الملفات |

`fetch` لا يدعم قياس تقدّم الرفع، لذلك الدالتان الأخيرتان تستخدمان `XMLHttpRequest`.

### [9] المصادقة — `AuthenticateApiToken.php`

```php
$token = $request->bearerToken();
$user  = User::where('api_token', hash('sha256', $token))
             ->where('is_active', true)->first();
```

نقاط مهمة:

- **التوكن الخام لا يُخزَّن.** يُحفظ `sha256` منه فقط، فتسريب قاعدة البيانات لا يمنح جلسات.
- **`is_active` جزء من الاستعلام.** تعطيل موظف يُنهي جلسته فوراً في الطلب التالي.
- الرسالة عند الفشل عربية ثابتة، والرمز 401.

### [11] التحقق — `TransitionReportRequest.php`

`FormRequest` يعمل قبل جسم المتحكم. عند الفشل يرجع 422 بالشكل:

```json
{
  "message": "The given data was invalid.",
  "errors": { "action": ["..."] }
}
```

الفرونت يقرأ `data.message` في `http.js` ويرميه كـ`Error`، فيظهر في مكوّن `Feedback.jsx`.

### [14] قواعد العمل — `ReportRepository.php`

فحصان منفصلان قبل أي تعديل:

| الفحص | الملف | السؤال |
| --- | --- | --- |
| `canManage()` | `Services/ReportAccessService.php` | هل هذا التقرير ضمن نطاق المستخدم وحالته الحالية؟ |
| `ensureAllowedTransition()` | `Repositories/Eloquent/ReportRepository.php` | هل هذا الانتقال تحديداً مسموح لدوره من هذه الحالة؟ |

الفصل مقصود: الأول يجيب "هل يخصّني؟" والثاني "هل يجوز هذا الفعل؟".

كل التعديلات داخل `DB::transaction` — إن فشل إنشاء الإشعار يُلغى تغيير الحالة أيضاً.

### [15] تشكيل الخرج — `ReportResource.php`

الـResource هو **العقد** بين الخادم والواجهة. إضافة عمود إلى الجدول لا تظهر في الواجهة
حتى تضيفه هنا. هذا مقصود: يمنع تسريب أعمدة حساسة دون قصد.

## المسارات الأخرى للطلب

### طلب برفع ملف

```
Page/Drive/index.jsx
   └─► api.uploadDriveFiles(files, data, onProgress)
         └─► http.js :: requestUpload()        ← XHR لأجل التقدّم
               └─► POST /api/drive-files       ← Content-Type يُترك للمتصفح
                     └─► DriveController::store()
                           ├─ فحص الحصة (role_drive_quotas)
                           ├─ إنشاء المجلد الفيزيائي إن لزم
                           ├─ حفظ الملف باسمه الأصلي مع (2) عند التكرار
                           └─ DriveFile::create()
```

فرق جوهري: عند `FormData` تحذف `http.js` ترويسة `Content-Type` عمداً، ليضع المتصفح
`multipart/form-data` مع الـ`boundary` الصحيح.

### طلب يولّد وثيقة Word

```
Page/Hr/index.jsx  ──► api.decideHrRequest(id, {action:'approve'})
   └─► POST /api/hr/requests/{id}/decision
         └─► HrRequestController::decide()
               └─► HrWorkflowService::approve()          ← DB::transaction
                     ├─ HrRequestAction::create()        سجل القرار
                     ├─ تحديث stage و status
                     ├─ عند المحطة الأخيرة:
                     │    ├─ consumeBalance()            خصم الرصيد
                     │    └─ HrDocumentService::generate()
                     │          ├─ DocxTemplateRenderer  تعبئة القالب
                     │          ├─ SimpleQrImage         توليد QR
                     │          ├─ SignatureImage        إدراج التوقيع
                     │          └─ DocxPdfConverter      DOCX ← PDF
                     └─ CndNotification::create()        إشعار الموظف
```

## أين تضع الكود؟ — جدول القرار السريع

| ما تكتبه | ضعه في |
| --- | --- |
| فحص أن الحقل رقم بين 1 و10 | `Requests/` |
| فحص أن المستخدم يملك السجل | `Services/` (خدمة نطاق) |
| استعلام معقّد بعلاقات | `Repositories/Eloquent/` |
| تحديد الحقول الظاهرة للواجهة | `Resources/` |
| علاقة أو `cast` أو سمة محسوبة | `app/Models/` |
| منطق يخصّ موديولين | `app/Services/` أو خدمة في الموديول المالك |
| فرض صلاحية | `Routes/api.php` عبر `->middleware('permission:...')` |
