# نظرة عامة على المعمارية

## المبدأ الحاكم

المشروع **مفصول تماماً**: الفرونت أند تطبيق SPA مستقل، والباك أند API خالص لا يُصدِر HTML.
لا يوجد Blade ولا Inertia. كل تواصل بينهما عبر JSON على HTTP، وقناة WebSocket واحدة للبث اللحظي.

القاعدة الذهبية في المشروع: **الصلاحية والنطاق يُطبَّقان في الخادم، لا في إخفاء عناصر الواجهة**.
إخفاء زر في الواجهة تحسين تجربة فقط؛ الحماية الحقيقية في `Routes/api.php` و`Services`.

## الطبقات في الباك أند ومسؤولياتها

| الطبقة | المسؤولية | لا يجوز أن تفعل |
| --- | --- | --- |
| **Routes** `Modules/*/Routes/api.php` | تعريف المسار وربطه بمتحكم + فرض الصلاحية | منطق عمل |
| **Middleware** `app/Http/Middleware/` | المصادقة واللغة | قواعد نطاق |
| **Request** `Modules/*/Requests/` | التحقق من صحة المدخلات وأنواعها | استعلامات معقّدة |
| **Controller** `Modules/*/Controllers/` | تنسيق: يستقبل، يفوّض، يُرجع | قواعد عمل مفصّلة |
| **Service** `Modules/*/Services/` | قواعد العمل والنطاق والانتقالات | تشكيل JSON |
| **Repository** `Modules/*/Repositories/` | بناء الاستعلامات والكتابة | فحص صلاحيات |
| **Resource** `Modules/*/Resources/` | تشكيل الاستجابة | جلب بيانات إضافية |
| **Model** `app/Models/` | العلاقات والقوالب (casts) والسمات المحسوبة | قواعد عمل |

> ليست كل الموديولات تستخدم كل الطبقات. `Drive` مثلاً يضع المنطق في المتحكم مباشرة،
> بينما `Reports` يفصل Repository + Service. عند التعديل التزم بنمط الموديول الذي تعدّله.

## قرارات معمارية مهمة ولماذا اتُّخذت

| القرار | السبب | الملف |
| --- | --- | --- |
| توكن مخصص بدل Sanctum | بساطة: عمود `api_token` واحد في `users` يخزّن `sha256` للتوكن | `app/Http/Middleware/AuthenticateApiToken.php` |
| تحميل المسارات بـ`glob` | إضافة موديول جديد لا تتطلب تعديل `routes/api.php` | `BackEnd/routes/api.php` |
| `JsonResource::withoutWrapping()` | إلغاء غلاف `data` ليقرأ الفرونت الاستجابة مباشرة | `app/Providers/AppServiceProvider.php` |
| `ShouldBroadcastNow` | البث فوري بلا انتظار عامل الطوابير | `app/Events/MessageCreated.php` |
| مسار `/status` بجانب `/system/health` | بعض حاجبات الإعلانات تحجب المسارات التي تحوي `system/health` | `Modules/Core/Routes/api.php` |
| حفظ سبب الإعادة في الكاش لا في جدول | السبب مؤقت ويُحذف عند إعادة الإرسال؛ صلاحيته 14 يوماً | `Modules/Reports/Repositories/Eloquent/ReportRepository.php` |
| مجلدات Drive فيزيائية حقيقية | ليتمكن مدير النظام من تصفح الملفات من نظام التشغيل | `Modules/Drive/Controllers/DriveController.php` |
| توليد Word بمحرك ZIP يدوي | تجنّب اعتماد PHPWord؛ الحاجة محدودة باستبدال متغيرات وإدراج صور | `app/Services/Documents/DocxTemplateRenderer.php` |
| ثلاثة اتصالات PostgreSQL | فصل صلاحيات المالك/التطبيق/القراءة | `BackEnd/config/database.php` |
